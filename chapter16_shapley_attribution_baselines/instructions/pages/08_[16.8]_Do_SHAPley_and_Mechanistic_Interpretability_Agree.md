# Introduction


Different interpretability methods often score different kinds of players:
tokens, training examples, activation slices, heads, SAE features, edges, or
directions. Raw scores are therefore not always directly comparable. A better
question is whether the methods agree through consequences: deleting, inserting,
ablating, or patching the claimed important player should change the task metric
as predicted.

This notebook starts with GT-0 Boolean-style controls. In an additive game,
Shapley values, patching effects, and mechanistic ground-truth scores agree. In
an XOR/parity game, ordinary single-feature Shapley values miss the causal pair,
while interaction values recover it.

The checked GPU preflight trains the nonlinear CUDA neural coalition game used
throughout the Shapley track, compares Shapley values from real ablated model
outputs against known analytic mechanistic feature contributions, checks
rank/top-k/deletion agreement, verifies the planted pair interactions, and
rejects a shuffled-label trained-model control.

> ##### Learning Objectives

### 3. CUDA agreement preflight

The verification path tests agreement on a trained finite model organism.

> ##### Learning Objectives
>
> * Compare Shapley scores with known mechanistic scores on model outputs.
> * Validate agreement through deletion and pair-interaction consequences.
> * Reject shuffled-label agreement as a negative control.
> * Save `agreement_matrix.csv`, deletion/insertion curves, a top-k overlap
>   heatmap, and disagreement examples from the same run.

# Agreement on additive ground truth


### Exercise - compare rankings and deletion consequences

> ```yaml
> Difficulty: medium
> Importance: high
>
> You should spend up to 10 mins on this exercise.
> ```

The mechanistic ground truth is additive: feature 1 matters most, then feature
0, then feature 2. Shapley values should recover the same ranking, and deleting
the top feature should damage the metric more than deleting a non-top feature.

```python
mechanistic_scores = t.tensor([1.0, 2.0, 0.5])
values = additive_game(mechanistic_scores)
report = attribution_agreement_report(
    values,
    mechanistic_scores=mechanistic_scores,
    num_players=3,
)

utils.print_report("Additive agreement", report.__dict__)

assert report.agrees_with_mechanistic
assert report.deletion_drop > report.random_baseline_drop


def additive_agreement_smoke_test() -> dict:
    mechanistic_scores = t.tensor([1.0, 2.0, 0.5])
    values = additive_game(mechanistic_scores)
    result = attribution_agreement_report(
        values,
        mechanistic_scores=mechanistic_scores,
        num_players=3,
    ).__dict__.copy()
    result["shapley_values"] = result["shapley_values"].tolist()
    result["patching_effects"] = result["patching_effects"].tolist()
    result["mechanistic_scores"] = result["mechanistic_scores"].tolist()
    return result


tests.test_additive_agreement_smoke_test(additive_agreement_smoke_test)
```

# Disagreement on XOR interactions


### Exercise - recover the causal pair

> ```yaml
> Difficulty: medium
> Importance: high
>
> You should spend up to 10 mins on this exercise.
> ```

In XOR, neither feature has a nonzero ordinary Shapley value at the full
coalition. The causal story is the pair interaction.

```python
report = interaction_agreement_report(xor_game())

utils.print_report("XOR disagreement", report.__dict__)

assert report.ordinary_shapley_misses
assert report.interaction_recovers_pair


def xor_disagreement_smoke_test() -> dict:
    result = interaction_agreement_report(xor_game()).__dict__.copy()
    result["shapley_values"] = result["shapley_values"].tolist()
    result["pair_interactions"] = result["pair_interactions"].tolist()
    return result


tests.test_xor_disagreement_smoke_test(xor_disagreement_smoke_test)
```
