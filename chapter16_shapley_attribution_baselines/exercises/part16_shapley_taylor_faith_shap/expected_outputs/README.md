# Shapley-Taylor and Faith-Shap execution evidence

The learner notebooks are the teaching artifact. This directory holds the
supporting records that bind their actual execution, figures and independent
fresh reproduction. The full native development learner has run successfully, including all eleven figures and
all 1,735 predeclared tensor leaves. Publication and the normal registered report remain
pending; development evidence is retained in the persistent `shapley_interactions` cache.

## How this fixture was produced

`execute_learner.py` completes the exercise notebook from its own Solution
dropdowns, checks the visible core functions against the reference answers and
executes it in a new CPU kernel. The native capstone refits all seven known
predictors, verifies all 21 prior model-state hashes, seals preparation before
loading the audit split, and retains every declared deterministic result.
`reproduce_native.py` launches a separate process with only an output path; that
process refits the models and recreates all calculations without learner model
inputs. Every deterministic numerical leaf is compared by exact value hashes.
Wall-clock measurements are retained separately as descriptive measurements.

`publish_study.py` requires the actual executed notebook, full reproduction,
source-bound browser/figure review and current screenshot/image bytes. It
publishes the paired notebooks, page and eleven namespaced figures together
with `learner_execution.json`, `native_summary.json`, `fresh_reproduction.json`
and `execution.tar.gz`. These filenames describe required future records until
the publication operation actually succeeds.

## Trusted implementation and independent oracles

The eight fixed rational-dividend games isolate constant, additive, signed
pair, triple, four-way and mixed mechanisms. Fifteen seeded random games cover
orders one through three, with five separately counted order-n boundaries.
Independent discrete-derivative Shapley-Taylor and pair-SII formulas, the
Faith-Shap closed form and a separate equality-constrained KKT solve check the
student's functions. Direct `shapiq==1.5.2` calls cover every empirical game and
all 58 exact game instances. The mathematical sources are the
[Shapley-Taylor paper](https://proceedings.mlr.press/v119/sundararajan20a.html)
and [Faith-Shap paper](https://www.jmlr.org/papers/v24/22-0202.html).

The frozen protocol specifies separate scale-dependent bounds for exact
formulas, package coordinates and package FSII endpoint residuals. The package
uses a finite endpoint penalty; its looser numerical comparison does not alter
the exact constrained problem taught in the notebook. Every raw vector,
comparison mask, signed error and package/source identity is retained.

## Random seed and frozen protocol

`data_manifest.json` fixes source bytes, row/group identities, model seeds,
donor orders, literal analytic games, private random streams, default play IDs,
and complete output shapes. `protocol.md` states the scientific definitions and
numerical rules. The original `protocol_freeze.json` records zero preceding native fits,
model-game runs, attributions and audit loads and authorizes development execution only.
Its independent-approval field is false. Root resolutions and dated implementation
corrections are recorded separately without rewriting that initial freeze. Publication
still requires a genuine independent recheck of the final executed source and design.

The ten explanation/audit hybrid shards hold 50,135,040 unique donor predictions.
Their live files, full manifests, value hashes and physical file hashes are
checked during reproduction and reporting. Archives inline files up to 128 MiB;
larger numerical files remain bound to their persistent cache paths and must
remain available for reproduction checks. Primary64 aliases reference the same
clean_0 tensors and do not count as additional physical arrays.

The report's legacy `run_gpu_test` entry name executes on CPU. A normal report
run performs another actual fresh process and records its own output path and
hashes. It does not count a previously fitted learner model as a new report fit.
The validation gates check complete scope and implementation correctness;
method agreement, reconstruction size and ranking superiority are scientific
results, never success criteria. Observational donor games do not establish
physical causality, and these known Concrete models are not an independent
model or dataset replication.
