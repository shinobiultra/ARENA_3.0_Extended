## Maintainer compatibility note

The combined module postpones annotations with `from __future__ import annotations`. The original
VLM standalone declarations used eager annotations, so raw `__annotations__`, signature annotation
objects and dataclass Field.type introspection differ. The independent declaration-only review
found equal resolved typing.get_type_hints for all 23 annotated VLM reference declarations after
the declared names were mapped, and found no annotation-value consumer in its bounded source
audit. This does not prove runtime identity for external introspection clients. Root accepted this
nonnumeric compatibility delta; no annotation-mutation bridge or scientific method change is added.
Original eager-annotation source bytes remain in the durable original-source archive. See the
hash-bound 16.7 review in the follow-on integration evidence.
