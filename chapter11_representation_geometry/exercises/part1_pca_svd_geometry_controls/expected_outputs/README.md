# Measured geometry outputs and numerical fixtures

## How this fixture was produced

The learner is completed from its own answer dropdowns and executed in a fresh
Jupyter kernel. The exact-model ring and nuisance variable test known algebra.
The Mistral study generates its own prompts, fits only training activations,
retains all development boundaries and evaluates frozen new templates. Actual
calendar logits and full-vocabulary winners are stored for every intervention.

## Trusted implementation

`geometry_methods_tests.py` uses independent SVD/KKT/rank-distance oracles,
scikit-learn trustworthiness parity, a deterministic exact calendar model,
padding checks and hook cleanup checks. The notebook passes its own functions
to these tests. An independently loaded model regenerates a fixed first batch
for all eight planned conditions and all 32 draws of three null conditions.

## Random seed

The complete seed, split and selected-layer specification is in
`geometry_protocol.json`. Selection was frozen before final inference. Reducer
seeds are 0 through 4, with three settings each for UMAP and t-SNE. All nulls
remain included, even strong ones. The source snapshots preserve the exact code.

## Allowed tolerances

Numerical tests use rtol=1e-5 and atol=1e-6 where specified; exact invariants use
exact equality. Fresh BF16 native-model reproduction on identical ordered batches
requires maximum calendar-logit error at most 1e-6 and exact top-token agreement.
These bounds check reproduction, not a desired scientific outcome.

## When to regenerate

Regenerate scientific evidence when methods, data, model revision, fitting or
intervention choices change. Prose may be updated after inspecting outcomes
when the executed code is unchanged. The one recorded angle-plot heading repair
was rendered from the same saved measurements, with numerical plotting code
verified unchanged. A new seed or final prompt is a new experiment, not a repair
to an unwanted result.
