# Introduction

SAEs and transcoders usually decompose one model. Crosscoders compare two
models. The question changes from "what features does this model use?" to "what
features are shared, and what features explain the difference between these two
systems?"

The roadmap examples include base vs instruction-tuned models, GPT-style vs
Pythia-style models, and toy Transformer vs toy Mamba pairs. In all cases the
same validation ladder matters:

1. reconstruct both activation spaces,
2. identify shared and model-specific features,
3. test whether model-specific features predict behavior deltas,
4. ablate or steer those features,
5. compare against random or orthogonal controls.

The current real-model report is an honest preflight, not a full trained
crosscoder paper replication. It loads two small public TransformerLens
checkpoints, pairs safe prompt categories, decomposes final residual-stream
deltas with SVD, and checks that the top direction separates the prompt labels
and reduces activation-space model deltas more than an orthogonal random
direction.


## Content & Learning Objectives

### 1. Shared and model-specific reconstruction

> ##### Learning Objectives
>
> * Decode shared latent features into both model activation spaces.
> * Decode model-specific features into only the corresponding model space.
> * Treat reconstruction as necessary but not sufficient for a model-diff claim.

### 2. Feature specificity

> ##### Learning Objectives
>
> * Classify features as shared, model-A-specific, or model-B-specific.
> * Use a threshold so tiny mean differences are not overinterpreted.
> * Keep feature ownership as a hypothesis until behavior tests support it.

### 3. Behavior-delta prediction

> ##### Learning Objectives
>
> * Define paired behavior deltas with an explicit direction.
> * Use signed AUC to catch both positive and negative predictive directions.
> * Require matched positive and negative examples.

### 4. Ablation controls

> ##### Learning Objectives
>
> * Measure behavior-delta reduction after feature ablation.
> * Compare model-specific ablation against random matched-feature ablation.
> * Reject features that predict labels but fail causal controls.

```python
def decode_crosscoder(
    shared_acts: t.Tensor,
    model_a_specific_acts: t.Tensor,
    model_b_specific_acts: t.Tensor,
    shared_decoder_a: t.Tensor,
    shared_decoder_b: t.Tensor,
    model_a_decoder: t.Tensor,
    model_b_decoder: t.Tensor,
) -> CrosscoderOutput:
    if shared_acts.shape[-1] != shared_decoder_a.shape[0]:
        raise ValueError("shared feature dimension must match model A shared decoder rows.")
    if shared_acts.shape[-1] != shared_decoder_b.shape[0]:
        raise ValueError("shared feature dimension must match model B shared decoder rows.")
    if model_a_specific_acts.shape[-1] != model_a_decoder.shape[0]:
        raise ValueError("model A feature dimension must match model A decoder rows.")
    if model_b_specific_acts.shape[-1] != model_b_decoder.shape[0]:
        raise ValueError("model B feature dimension must match model B decoder rows.")

    reconstructed_a = shared_acts.float() @ shared_decoder_a.float()
    reconstructed_a = reconstructed_a + model_a_specific_acts.float() @ model_a_decoder.float()
    reconstructed_b = shared_acts.float() @ shared_decoder_b.float()
    reconstructed_b = reconstructed_b + model_b_specific_acts.float() @ model_b_decoder.float()
    return CrosscoderOutput(shared_acts, model_a_specific_acts, model_b_specific_acts, reconstructed_a, reconstructed_b)


def crosscoder_reconstruction_report(
    model_a_activations: t.Tensor,
    model_b_activations: t.Tensor,
    output: CrosscoderOutput,
    *,
    mse_threshold: float = 1e-6,
) -> CrosscoderReconstructionReport:
    model_a_mse = F.mse_loss(output.reconstructed_model_a.float(), model_a_activations.float()).item()
    model_b_mse = F.mse_loss(output.reconstructed_model_b.float(), model_b_activations.float()).item()
    shared_active_fraction = output.shared_acts.gt(0).float().mean().item()
    model_a_passes = model_a_mse <= mse_threshold
    model_b_passes = model_b_mse <= mse_threshold
    return CrosscoderReconstructionReport(
        model_a_mse=model_a_mse,
        model_b_mse=model_b_mse,
        shared_active_fraction=shared_active_fraction,
        model_a_passes=model_a_passes,
        model_b_passes=model_b_passes,
        shared_reconstructs_both=model_a_passes and model_b_passes,
    )
```

```python
def feature_specificity_report(
    model_a_feature_acts: t.Tensor,
    model_b_feature_acts: t.Tensor,
    feature_id: int,
    *,
    shared_threshold: float = 0.1,
) -> FeatureSpecificityReport:
    if model_a_feature_acts.shape != model_b_feature_acts.shape:
        raise ValueError("model feature activation tensors must have matching shapes.")
    if feature_id < 0 or feature_id >= model_a_feature_acts.shape[-1]:
        raise IndexError("feature_id is out of range.")
    model_a_mean = model_a_feature_acts[..., feature_id].float().mean().item()
    model_b_mean = model_b_feature_acts[..., feature_id].float().mean().item()
    specificity = model_b_mean - model_a_mean
    if abs(specificity) <= shared_threshold:
        owner = "shared"
    elif specificity > 0:
        owner = "model_b"
    else:
        owner = "model_a"
    return FeatureSpecificityReport(feature_id, model_a_mean, model_b_mean, specificity, owner)


def classify_features_by_specificity(
    model_a_feature_acts: t.Tensor,
    model_b_feature_acts: t.Tensor,
    *,
    shared_threshold: float = 0.1,
) -> list[FeatureOwner]:
    return [
        feature_specificity_report(
            model_a_feature_acts,
            model_b_feature_acts,
            feature_id,
            shared_threshold=shared_threshold,
        ).owner
        for feature_id in range(model_a_feature_acts.shape[-1])
    ]
```

### Exercise - score behavior-delta prediction

> ```yaml
> Difficulty: medium
> Importance: high
>
> You should spend up to 15 mins on this exercise.
> ```

If a model-specific feature explains a behavior change, it should predict which
paired prompts show that behavior delta. Use signed AUC so both high-score and
low-score predictive directions can pass, but keep positive and negative means
for interpretability.

Common bug: reporting accuracy at one arbitrary threshold without checking rank

```python
def roc_auc_binary(scores: t.Tensor, labels: t.Tensor) -> float:
    scores = scores.detach().flatten().float()
    labels = labels.detach().flatten().bool()
    if scores.numel() != labels.numel():
        raise ValueError("scores and labels must have the same number of elements.")
    n_pos = int(labels.sum().item())
    n_neg = int((~labels).sum().item())
    if n_pos == 0 or n_neg == 0:
        raise ValueError("AUC requires at least one positive and one negative example.")

    order = scores.argsort()
    sorted_scores = scores[order]
    ranks_sorted = t.empty_like(sorted_scores)
    _, counts = t.unique_consecutive(sorted_scores, return_counts=True)
    start = 0
    for count in counts.tolist():
        end = start + count
        ranks_sorted[start:end] = (start + 1 + end) / 2
        start = end
    ranks = t.empty_like(scores)
    ranks[order] = ranks_sorted
    pos_rank_sum = ranks[labels].sum()
    auc = (pos_rank_sum - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)
    return float(auc.item())


def behavior_delta_prediction_report(
    feature_scores: t.Tensor,
    behavior_delta_labels: t.Tensor,
    *,
    feature_id: int,
    min_auc: float = 0.8,
) -> BehaviorDeltaPredictionReport:
    scores = feature_scores.flatten().float()
    labels = behavior_delta_labels.flatten().bool()
    if scores.numel() != labels.numel():
        raise ValueError("feature_scores and behavior_delta_labels must have equal length.")
    auc = roc_auc_binary(scores, labels)
    signed_auc = max(auc, 1.0 - auc)
    positives = scores[labels]
    negatives = scores[~labels]
    if positives.numel() == 0 or negatives.numel() == 0:
        raise ValueError("Need at least one positive and one negative example.")
    return BehaviorDeltaPredictionReport(
        feature_id=feature_id,
        auc=signed_auc,
        positive_mean=positives.mean().item(),
        negative_mean=negatives.mean().item(),
        passes_threshold=signed_auc >= min_auc,
    )
```

```python
def crosscoder_ablation_report(
    baseline_behavior_deltas: t.Tensor,
    ablated_behavior_deltas: t.Tensor,
    random_ablated_behavior_deltas: t.Tensor,
) -> CrosscoderAblationReport:
    baseline_delta = baseline_behavior_deltas.float().mean().item()
    ablated_delta = ablated_behavior_deltas.float().mean().item()
    random_delta = random_ablated_behavior_deltas.float().mean().item()
    baseline_abs = abs(baseline_delta)
    ablated_abs = abs(ablated_delta)
    random_abs = abs(random_delta)
    delta_reduction = baseline_abs - ablated_abs
    random_reduction = baseline_abs - random_abs
    return CrosscoderAblationReport(
        baseline_delta=baseline_delta,
        ablated_delta=ablated_delta,
        random_ablated_delta=random_delta,
        delta_reduction=delta_reduction,
        random_reduction=random_reduction,
        passes_control=delta_reduction > random_reduction,
    )
```

# Full Experiment Path

The full crosscoder model-diffing experiment should train on paired activations
from two models:

1. Choose a pair: base vs instruction-tuned, GPT-style vs Pythia-style, or toy Transformer vs toy Mamba.
2. Build paired prompts and cache activations at matching hook points or aligned representation layers.
3. Train or construct a crosscoder with shared and model-specific feature groups.
4. Verify that shared features reconstruct both model activation spaces.
5. Identify model-specific features and score them against behavior deltas.
6. Test behavior deltas for refusal, verbosity, tool-call formatting, chain-of-thought style, or unsafe-code refusal.
7. Ablate or steer model-specific features and compare against random matched controls.
8. Save model names, layers, prompts, seeds, feature ids, behavior labels, and validation reports.

The committed CUDA path uses pinned `gelu-1l` and `solu-1l` final-token residual
streams as a compact paired-checkpoint model-diffing preflight.

Expected output from `run_gpu_test(max_vram_gb=24.0)`:

```text
preflight_passed == True
shared_reconstructs_both == True
behavior_delta_auc == 1.0
top_variance_fraction >= 0.25
delta_reduction >= 1.0
random_reduction <= 0.1
ablation_passes_control == True
peak_vram_gb <= 1.0
```

Common bug: calling a feature "model-specific" because it reconstructs one model,
without showing that it predicts or causally affects a behavior delta.
