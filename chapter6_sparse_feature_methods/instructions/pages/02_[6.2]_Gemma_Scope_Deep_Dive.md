# Introduction

The previous section compared SAE variants on toy data. In practice, you usually should not train a huge SAE yourself if a strong released artifact already exists. Gemma Scope-style artifacts let you inspect features from modern Gemma-family models, but the interpretation workflow still needs discipline. A released feature is a coordinate system, not an explanation.

A feature is not "understood" because its top activations look plausible. For a feature related to refusal, code, sentiment, names, languages, formatting, or chain-of-thought markers, the minimum validation loop is:

1. record artifact metadata,
2. select a tagged feature,
3. score held-out positives and matched negatives,
4. compare against a baseline or random feature,
5. compare base and instruction-tuned activations where available,
6. test ablation and steering against controls,
7. inspect direct logit attribution as a hypothesis generator.

The committed GPU report downloads or reuses `google/gemma-scope-2-1b-it` revision
`b0fa29457c3601df0a70c48a15534c738d7c10e0`, checks the layer-13 residual SAE tensor
shapes `[1152, 16384]` and `[16384, 1152]`, verifies finiteness, executes the JumpReLU
SAE forward pass on CUDA, and runs authenticated `google/gemma-3-1b-it` residual
activations through the SAE. The real-activation path checks one benign
technical-vs-narrative feature hypothesis against random-feature and label-shuffle
controls.

<img src="../assets/gemma_scope_validation_ladder.svg" width="820">

The point of this section is not "Gemma Scope has solved interpretability." The point is that a released feature artifact can be used responsibly only when its metadata, prompt scoring rule, baselines, controls, and claim boundary are all visible.


## Content & Learning Objectives

### 1. Artifact metadata and tags

> ##### Learning Objectives
>
> * Treat model name, layer, hook, artifact type, and feature count as required metadata.
> * Use tags to organize feature hypotheses.
> * Keep feature descriptions separate from validation evidence.

### 2. Held-out feature validation

> ##### Learning Objectives
>
> * Reduce per-token feature activations to one score per prompt.
> * Compare AUC against a baseline feature or shuffled control.
> * Use matched negatives instead of only top activations.

### 3. Base-vs-instruction comparison

> ##### Learning Objectives
>
> * Measure behavior deltas without assuming the sign in advance.
> * Use feature deltas to prioritize candidate safety or instruction-following features.
> * Keep activation differences separate from causal claims.

### 4. Ablation, steering, and DLA

> ##### Learning Objectives
>
> * Compare ablation against random-feature ablation.
> * Bound steering side effects with a perplexity guard.
> * Use direct logit attribution as a hypothesis generator, not proof.

def feature_score_vector(
    feature_acts: t.Tensor,
    feature_id: int,
    *,
    reduction: Literal["max", "mean", "last"] = "max",
) -> t.Tensor:
    if feature_acts.ndim == 2:
        if feature_id < 0 or feature_id >= feature_acts.shape[-1]:
            raise IndexError("feature_id is out of range.")
        return feature_acts[:, feature_id].float()
    if feature_acts.ndim != 3:
        raise ValueError(
            "feature_acts must have shape (examples, features) or (examples, seq, features)."
        )
    if feature_id < 0 or feature_id >= feature_acts.shape[-1]:
        raise IndexError("feature_id is out of range.")

    per_token = feature_acts[..., feature_id].float()
    if reduction == "max":
        return per_token.max(dim=-1).values
    if reduction == "mean":
        return per_token.mean(dim=-1)
    if reduction == "last":
        return per_token[:, -1]
    raise ValueError("reduction must be 'max', 'mean', or 'last'.")
```
</details>

def roc_auc_binary(scores: t.Tensor, labels: t.Tensor) -> float:
    scores = scores.detach().flatten().float()
    labels = labels.detach().flatten().bool()
    if scores.numel() != labels.numel():
        raise ValueError("scores and labels must have the same number of elements.")
    n_pos = int(labels.sum().item())
    n_neg = int((~labels).sum().item())
    if n_pos == 0 or n_neg == 0:
        raise ValueError("AUC requires at least one positive and one negative example.")

    order = scores.argsort()
    sorted_scores = scores[order]
    ranks_sorted = t.empty_like(sorted_scores)
    _, counts = t.unique_consecutive(sorted_scores, return_counts=True)
    start = 0
    for count in counts.tolist():
        end = start + count
        average_rank = (start + 1 + end) / 2
        ranks_sorted[start:end] = average_rank
        start = end
    ranks = t.empty_like(scores)
    ranks[order] = ranks_sorted
    pos_rank_sum = ranks[labels].sum()
    auc = (pos_rank_sum - n_pos * (n_pos + 1) / 2) / (n_pos * n_neg)
    return float(auc.item())


def validate_feature_scores(
    feature_scores: t.Tensor,
    labels: t.Tensor,
    baseline_scores: t.Tensor,
    *,
    min_auc_margin: float = 0.1,
) -> FeatureValidationSuiteReport:
    feature_scores = feature_scores.detach().flatten().float()
    labels = labels.detach().flatten().bool()
    positives = feature_scores[labels]
    negatives = feature_scores[~labels]
    if positives.numel() == 0 or negatives.numel() == 0:
        raise ValueError("Need at least one positive and one negative example.")

    threshold = 0.5 * (positives.mean().item() + negatives.mean().item())
    threshold_accuracy = feature_scores.ge(threshold).eq(labels).float().mean().item()
    feature_auc = roc_auc_binary(feature_scores, labels)
    baseline_auc = roc_auc_binary(baseline_scores.flatten().float(), labels)
    auc_margin = feature_auc - baseline_auc
    return FeatureValidationSuiteReport(
        feature_auc=feature_auc,
        baseline_auc=baseline_auc,
        auc_margin=auc_margin,
        threshold_accuracy=threshold_accuracy,
        positive_mean=positives.mean().item(),
        negative_mean=negatives.mean().item(),
        passes_baseline=auc_margin >= min_auc_margin,
    )
```
</details>

def base_instruction_feature_delta(
    base_scores: t.Tensor,
    instruction_scores: t.Tensor,
) -> BaseInstructionFeatureDelta:
    if base_scores.shape != instruction_scores.shape:
        raise ValueError("base_scores and instruction_scores must have matching shapes.")
    base_mean = base_scores.float().mean().item()
    instruction_mean = instruction_scores.float().mean().item()
    delta = instruction_mean - base_mean
    return BaseInstructionFeatureDelta(
        base_mean=base_mean,
        instruction_mean=instruction_mean,
        delta=delta,
        abs_delta=abs(delta),
    )
```

def ablation_control_report(
    baseline_scores: t.Tensor,
    ablated_scores: t.Tensor,
    random_ablated_scores: t.Tensor,
) -> AblationControlReport:
    baseline_mean = baseline_scores.float().mean().item()
    ablated_mean = ablated_scores.float().mean().item()
    random_mean = random_ablated_scores.float().mean().item()
    ablation_delta = baseline_mean - ablated_mean

        baseline_mean=baseline_mean,
        ablated_mean=ablated_mean,
        random_ablated_mean=random_mean,
        ablation_delta=ablation_delta,
        random_delta=random_delta,
        passes_control=ablation_delta > random_delta,
    )

def steering_safety_report(
    baseline_scores: t.Tensor,
    steered_scores: t.Tensor,
    random_control_scores: t.Tensor,
    *,
    baseline_perplexity: float,
    steered_perplexity: float,
    max_perplexity_ratio: float = 1.2,
) -> SteeringSafetyReport:
    if baseline_perplexity <= 0:
        raise ValueError("baseline_perplexity must be positive.")
    baseline_mean = baseline_scores.float().mean().item()
    steered_mean = steered_scores.float().mean().item()
    random_mean = random_control_scores.float().mean().item()

    random_delta = random_mean - baseline_mean

        baseline_mean=baseline_mean,
        steered_mean=steered_mean,
        random_mean=random_mean,
        steered_delta=steered_delta,
        random_delta=random_delta,
        perplexity_ratio=perplexity_ratio,

def direct_logit_attribution(
    decoder_vectors: t.Tensor,
    unembedding: t.Tensor,
    token_ids: t.Tensor | list[int] | None = None,
) -> t.Tensor:
    if decoder_vectors.ndim != 2 or unembedding.ndim != 2:
        raise ValueError("decoder_vectors and unembedding must both be rank-2 tensors.")
    if decoder_vectors.shape[-1] != unembedding.shape[0]:
        raise ValueError("decoder_vectors last dimension must match unembedding first dimension.")
    logit_effects = decoder_vectors.float() @ unembedding.float()
    if token_ids is None:
        return logit_effects
    return logit_effects[:, t.as_tensor(token_ids, device=logit_effects.device)]
```
</details>


# Full Experiment Path

The full Gemma Scope deep dive should load a real released SAE or transcoder artifact and use this exact validation loop:

1. Record artifact metadata: model, layer, hook, artifact type, feature count, dtype, source path, and commit or release identifier.
2. Choose candidate features tagged by hypothesis: refusal, code, sentiment, names, languages, formatting, or chain-of-thought markers.
3. Build held-out positives and matched negatives for each hypothesis.
4. Score prompts with max, mean, or last-token feature activation, and report which reduction was used.
5. Compare candidate AUC against random features and shuffled-label controls.
6. Compare base and instruction-tuned feature activations where matching artifacts exist.
7. Test ablation and steering against random matched features.
8. Compute direct logit attribution for target and anti-target tokens.
9. Save prompts, feature ids, scores, model metadata, random seeds, and validation reports.

The current checked CUDA path is narrower and explicit:

1. Load the pinned `google/gemma-scope-2-1b-it` SAE artifact.
2. Validate config fields and safetensor shapes.
3. Move the artifact to CUDA and run the JumpReLU encode/decode path.
4. Check the exact matching Gemma 3 1B IT base model access gate.
5. Encode authenticated Gemma 3 layer-13 activations through the released SAE and validate a benign semantic split against random-feature and label-shuffle controls.

The minimum acceptance criteria are:

```text
artifact metadata is complete enough to reload the feature
feature AUC beats random or shuffled-label baseline on held-out examples
ablation reduces the target behavior more than random-feature ablation
steering increases the target behavior without large perplexity blow-up
random matched features fail the same causal tests
direct logit attribution is treated as hypothesis generation, not proof
Gemma Scope artifact config, tensors, and forward pass are checked on CUDA
authenticated Gemma 3 activations pass semantic feature validation controls
```

## Limitations

This section does not claim that the selected feature is a robust human-interpretable
concept across distributions, that Gemma Scope features are causally validated in
general, or that direct logit attribution proves feature meaning. The real activation
validation uses a small benign prompt split, one selected feature, and one random-feature
control. Causal steering and ablation behavior on real Gemma activations remains future
work for later sparse-feature and circuit sections.
