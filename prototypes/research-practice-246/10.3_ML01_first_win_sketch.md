# [10.3] One Neuron, One Push: Reproducing a Neuron-Steering Result

# Introduction

Threads about a neuron-steering project quoted coordinates in a 27B model, an "evil" neuron and a "7 of 12" success rate. Before you replicate any of that,
apply step 1 of the recipe card: **who claimed what?**

The project the headline pointed to is Lyra's public [neuron-explorer](https://github.com/lyramakesmusic/neuron-explorer). It documents a 4B model, Qwen3.5-4B.
It contains no 27B coordinates, no "7 of 12" and no "evil" neurons. Those numbers come from a different person, working on a different model, as reported
by a news article, and they reportedly didn't reproduce. What the repository *does* document, carefully, is a sweep of every neuron in a layer against random
directions of the same size, and one benign neuron with logged prompts, doses and outputs: layer 22, neuron 2742, pushed positive, which gives the model an
alien persona.

So the claim you can actually test is Lyra's, not the headline's: *pushing L22 N2742 makes Qwen3.5-4B talk about being an alien across unrelated prompts, and a
random direction of the same size doesn't.*

In this section you will:

- implement a hook on the input of the MLP's `down_proj`, and the dose units that make pushes on different neurons comparable;
- reproduce the alien persona at Lyra's doses on Lyra's three prompts;
- run the control that Lyra's own log says matters: random directions of the same size, which can flip the model's stated name too;
- give a verdict and write a note with the same recipe card as [10.2].

Setup: about ‹measure: estimated ≤9 GB› of GPU memory and a few minutes of generation. The code is MIT-licensed and the model Apache-2.0.

## Outline

**1️⃣ Read.** Write the claim ladder for the headline *and* for Lyra's repo, side by side. The lesson of the opener: half the rungs belong to someone else.

**2️⃣ Reproduce.**
- Exercise: the dose unit. `alpha = dose * R_L / ||w_n||`, so the injected vector $\alpha w_n$ has length $|\text{dose}| \cdot R_L$ whatever the neuron.
  Worked check from #239: with $R = 100$, $\lVert w \rVert = 2$ and dose 0.1, you get $\alpha = 5$ and an injected norm of 10. Lyra's measured values at L22 are a
  median residual norm of 25.4 and a median down-column norm of 0.445. The learner recomputes $R_{22}$ on a small calibration set (position 0 excluded) and
  compares.
- Exercise: `push_neuron(model, layer, neuron, dose)` as a `down_proj` forward pre-hook, at every position. Tests: zero-dose parity, hook removed, and
  input-side and output-side equivalence on a tiny model.
- Run: Lyra's prompts ("Who are you?", "Write a snake game in Python.", "Describe the color orange."), greedy, 256 tokens, thinking off, at doses
  0, +0.5 and +0.8 (in residual-norm units). **Make a prediction first:** at which dose does the persona appear, and at which does the text break?

**3️⃣ Attack.**
- Random directions of the same length at the same doses. Lyra's log records that a random direction flipped the model's stated maker ("Xiaomi AI"), and
  that neighbouring neurons 2745, 2746 and 2748 gave Grok, Google and Microsoft. So a name flip on "Who are you?" is cheap and non-specific, and the test is
  *one theme across all three prompts*.
- A damage curve: the distinct-4-gram ratio against push size. Lyra's log says text breaks above about 1.5 times the residual norm, and sooner for real neuron
  directions than for random ones.

**4️⃣ Verdict and note.** The same `replication_verdict` and checklist as 10.2. Item 1 ("who claimed what?") gets the longest answer here.

**🎯 Held-out Quiz.** Draft: a negative push (dose −0.7) on N2742; a neighbouring neuron at the same dose; the dose where text breaks for a random direction
against N2742.

**☆ Bonus.** Lyra's targeted contrast-and-intervene method (`explorer/agent_methodology.md`), and a 384-neuron mini-sweep against 64 controls. That is ML02's
territory: discover a candidate yourself.
