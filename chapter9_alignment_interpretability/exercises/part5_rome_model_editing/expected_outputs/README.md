- unrelated-prompt KL and held-out-text perplexity;
- one localized Louvre continuation and its repetition fraction;
- norm details for the wrong-position, shuffled-target, and five random controls.

The learner-facing assets are generated from the same run:

- `rome_rank_one_toy_oracle.png` shows the exact toy write and orthogonal protection.
