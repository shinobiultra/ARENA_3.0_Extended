# Research Project Template

Use this folder when a course exercise becomes a capstone-style project. The
goal is to make the research claim auditable before any result is treated as
evidence.

Minimum end state:

- one precise research question
- one benchmark or dataset
- one baseline suite
- one mechanistic claim
- one causal validation suite
- one OOD or held-out split
- one negative control
- one reproducible script
- one paper-style figure
- one short writeup

Exploratory observations belong in `research_log.ipynb` and
`hypothesis_tracker.md`. Claims belong in `paper_skeleton.md` only after the
experiment registry names the run, seed, artifacts, baselines, controls, and
known failure modes.

Do not use this template to launder a pretty plot into a result. A plot counts
only when it predicts, intervenes, transfers, or fails honestly.
