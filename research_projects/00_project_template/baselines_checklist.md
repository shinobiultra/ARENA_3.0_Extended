# Baselines Checklist

- [ ] Strong simple baseline included
- [ ] Text-only or input-only baseline included where relevant
- [ ] Probe or linear baseline included for activation claims
- [ ] Random control included
- [ ] Label-shuffled or template-shuffled control included where labels exist
- [ ] Baseline hyperparameters recorded
- [ ] Baseline results written to `experiment_registry.csv`
- [ ] Baseline failure cases documented in `failure_modes.md`
