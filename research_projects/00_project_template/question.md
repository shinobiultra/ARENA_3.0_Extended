# Question

## Research Question

State one question in a form that can be answered by a benchmark, baseline, and
causal validation.

Example:

> Do mini Activation Oracles answer compositional activation questions more
> reliably than a bank of probes on held-out prompt templates?

## Mechanistic Claim

State the candidate mechanism in one sentence.

Example:

> Question conditioning lets the oracle combine latent state features that are
> linearly available but not separable by a single fixed probe.

## Falsifier

State what result would make the claim useless.

Example:

> The claim fails if the oracle does not beat text-only and probe baselines on
> held-out templates, or if random activations produce confident answers.
