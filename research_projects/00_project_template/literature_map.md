# Literature Map

Use this file to record the minimum reading needed for the project.

| Paper / Resource | Why It Matters | Implementation Target | Risk / Limitation |
| --- | --- | --- | --- |
| Primary method paper | Core claim to reproduce or test | Minimal local implementation | May not scale down cleanly |
| Main baseline | Strongest comparison | Baseline script or existing library | Baseline may need tuning |
| Negative-control reference | Failure mode to avoid | Control experiment | Control may be too easy |

Keep notes short and operational. The purpose is to choose experiments, not to
write a survey.
