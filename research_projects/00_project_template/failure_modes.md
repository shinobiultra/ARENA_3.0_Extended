# Failure Modes

Use this file to record what went wrong, including negative results.

Common failure modes:

- result disappears on held-out prompts
- UMAP/t-SNE structure is seed-dependent
- probe accuracy is high only on train data
- random direction performs as well as claimed direction
- intervention causes global degradation rather than targeted change
- text-only baseline solves the VLM task
- image-only baseline solves the purported multimodal task
- LoRA matches task accuracy but learns a different mechanism
- generated images collapse or become white noise

Negative results should stay in the project. They prevent repeated mistakes.
