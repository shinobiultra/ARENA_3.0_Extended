# Refusal Proxy Prompts v1

Small safe JSONL prompt artifact for testing the roadmap prompt contract. The
records are sanitized meta-prompts and policy-writing prompts; they do not
contain procedural harmful content.

Purpose:

- exercise the required prompt artifact schema
- provide counterfactual refusal/compliance pairs
- include train, validation, test, and OOD splits
- include one redacted placeholder record with a hash-only prompt reference

This is a schema fixture, not a real refusal-direction benchmark.
