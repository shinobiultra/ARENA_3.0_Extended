recurrent-state collection, standardized ridge probes, controlled SSM-state edits,
and confident-error ranking. Seven immediate test functions retain the original
lesson's checks. The solutions notebook preserves all fourteen historical code
cells and their outputs/counts; it has not been freshly executed during migration.

shuffled-label performance, and donor-state versus same-norm random intervention.

editable, with its saved position-accuracy result. Seven forecast/reflection pairs
ask for commitments before inspecting references.

archived `arena_ext/mamba.py`; it is a prerequisite, not learner-owned state-tracking
code. The current 5.3 Mamba lesson supplies architectural background but does not
replace the historical backbone. `tests.py` retains the seven original test bodies;
its scalar task oracle and import routing are local. `utils.py` contains no method.

This existing one-layer Mamba study does not establish the broader canonical
Transformer/Mamba-3 comparison. Old GPU release reports and the 130M extraction
preflight remain separate historical support, with their original identities.

explicitly called. Do not interpret an old `accepted` field as current acceptance.
