# JEPA source contracts: what chapter 14 lessons must correct

Ticket: shinobiultra/ARENA_3.0_Extended#236 (re-chart #242). Retrieved 2026-11-06. Read-only literature and repository inspection only: no model, data, checkpoint or cluster use, nothing installed or run.

"Correct" below means the lesson code and prose match the paper's (or official repo's) objective and update rule. Local reviews (`docs/mastery/research/inbox_20261103/jepa_family_sources.md`, `prh_jepa.md`) were used as a starting map and re-verified against the papers; where they were right this note just pins them.

## Method and evidence limits

- Papers: arXiv version shown on the abs page on 2026-11-06. Full text read from arXiv HTML/PDF for the method sections cited. For several HTML pages the tool returned only the first ~100k characters, so appendices were not all read (V-JEPA 2, V-JEPA 2.1, MJEPA, US-JEPA, PRH, LeJEPA, ACT-JEPA). For Audio-JEPA, A-JEPA, 3D-JEPA and SparseJEPA I read the PDF text myself. For the others a summarizing fetch tool read the page; the equations I rely on were taken from those summaries and are flagged "(summary)" where I did not see the equation text myself. Re-read those before a lesson quotes an equation.
- Repos: commit = default-branch HEAD on 2026-11-06 (not a release tag). A HEAD commit pins what I read, not what the paper authors ran.
- "No official code found" means the arXiv abs page lists none and (for 3D-JEPA) a web search found none; it is not proof none exists.
- The lesson `.md` pages, `syllabus.yaml` and the inbox notes are not committed in this worktree's checkout; I read them from the main checkout path (read-only). `docs/mastery/roadmap_requirement_registry.yml` does not exist at the path the inbox note links, so the registry's "T-JEPA and TC-JEPA time-series" grouping could not be re-read here.

## What lessons must change

1. **14.3 `jepa.jepa_vla` source.** Line 930 links arXiv 2602.10098 and calls it "VLA-JEPA". The configured ID is JEPA-VLA (2602.11832, Miao et al.). Link 2602.11832 for `jepa.jepa_vla` and describe it as frozen V-JEPA 2 embeddings fused into an existing VLA (no new JEPA loss). List VLA-JEPA (2602.10098) only as a separate reading.
2. **14.4 audio.** Add Audio-JEPA (Tuncay, Labbe, Benetos, Pellegrini, arXiv 2507.02915v2) next to A-JEPA (Fei, Fan, Huang, 2311.15830v3) and say they are different papers. For Audio-JEPA, teach: EMA target encoder over the whole spectrogram, random 40-60% patch masking, squared L2 on masked positions (Eq. 2); mention the repo's `norm_mse` default only as a difference.
3. **14.4 time series / alias.** `syllabus.yaml` line 703 "time series (T-JEPA)" becomes TS-JEPA. T-JEPA is the remote-sensing paper (2610.05731) and TC-JEPA is text-conditional I-JEPA (2605.03245); neither is a time-series model. Remove the same grouping from the PRH matrix row (`prh_jepa.md` line 57).
4. **14.4 3D-JEPA.** Replace "inspect spatial grouping and target definition" with: frozen pretrained 3D teacher (dVAE tokens), no EMA, cosine distance 1 - cos. Note the printed Eq. 3 sign is inconsistent with the prose; use the distance 1 - cos.
5. **14.4 SparseJEPA.** State that only the group-norm penalty is fully specified; the KL term's distribution and the teacher update are not defined in the paper, so no native-parity claim is possible and no code exists.
6. **14.4 update-rule summary.** Add a one-line "teacher / target" column or sentence per reading row: EMA (I-/V-/TS-/T-/A-/Audio-/MJEPA/ACT/BiJEPA/TC), frozen teacher (3D, US, V-JEPA 2.1 distilled), jointly trained target (VL-JEPA InfoNCE), none (MC-JEPA VICReg+flow, LLM-JEPA, LeJEPA), unspecified (SparseJEPA). This is the most useful single change for learners and costs little.
7. **V-JEPA 2-AC (14.3).** CEM with L1 latent goal distance is what the paper uses; soften the "do not infer ... this exact optimizer" sentence to say only hyperparameters differ.
8. **I-JEPA loss note (14.1/14.4).** Paper = squared L2; official code = smooth-L1 on layer-normed targets; 14.1 already notes the latter, so only add the paper side.
9. **Source pinning.** Put the arXiv versions and commits from the table into one place the pages link to. Papers with only v1 and no code (TS-, T-, TC-, 3D-, Sparse-, US-, VL-, MJEPA, JEPA-VLA) can be linked by arXiv version alone; do not invent commits. Repos with HEAD commits can be linked at those commits.
10. **Not required.** TS-JEPA vs T-JEPA text in 14.4 line 971, A-JEPA text, US-JEPA SALT note, MC-JEPA, LLM-JEPA and BiJEPA caveats in 14.4 are already correct; learner pages need no status wording about any of this.
