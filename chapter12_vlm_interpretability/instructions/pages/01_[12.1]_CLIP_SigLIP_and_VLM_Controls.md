# [12.1] CLIP, SigLIP, and VLM Controls

**Can image and caption encoders learn a shared space from paired examples, and which visual tokens
carry a pretrained model's match?**

Start with a cosine calculation, then build a complete RGB CNN and causal caption encoder. Train
both towers with CLIP and SigLIP losses, retrieve fresh pictures and captions, inspect mistakes, and
break the claim with matched controls. Finally extract embeddings and patch visual activations in
pinned real checkpoints. Original ARENA chapters 0–4 remain unchanged.

4. Score semantic retrieval with duplicate positives and honest tie handling.
5. Inspect controls, actual predictions and editable pixel/caption examples.
6. Extract real embeddings, cache activations and apply temporary patch hooks.
7. Compare object, background, same-size random and full-sequence interventions.

Allow two sittings (roughly 4–6 hours including implementation). Tiny training supports CPU or CUDA;

**Common bug:** fitting a projector on supplied labels or features can look like image learning. The full-encoder tests below require pixels, token content, gradients and fresh images.

```python
def _normalize(values: t.Tensor) -> t.Tensor:
    values = values.float()
    return values / values.norm(dim=-1, keepdim=True).clamp_min(1e-8)


def clip_contrastive_logits(
    image_embeddings: t.Tensor,
    text_embeddings: t.Tensor,
    *,
    logit_scale: float = 10.0,
) -> t.Tensor:
    if image_embeddings.ndim != 2 or text_embeddings.ndim != 2:
        raise ValueError("embeddings must be rank-2 matrices.")
    if image_embeddings.shape[1] != text_embeddings.shape[1]:
        raise ValueError("image and text embedding widths must match.")
    return logit_scale * (_normalize(image_embeddings) @ _normalize(text_embeddings).T)


def contrastive_alignment_report(
    logits: t.Tensor,
    *,
    min_accuracy: float = 1.0,
    min_positive_margin: float = 1.0,
) -> ContrastiveAlignmentReport:
    if logits.ndim != 2 or logits.shape[0] != logits.shape[1]:
        raise ValueError("paired retrieval logits must be square.")
    targets = t.arange(logits.shape[0], device=logits.device)
    image_accuracy = float((logits.argmax(dim=1) == targets).float().mean())
    text_accuracy = float((logits.argmax(dim=0) == targets).float().mean())
    diagonal = logits.diag()
    mask = t.eye(logits.shape[0], dtype=t.bool, device=logits.device)
    strongest_image_negative = logits.masked_fill(mask, float("-inf")).max(dim=1).values
    strongest_text_negative = logits.masked_fill(mask, float("-inf")).max(dim=0).values
    margin = float(
        t.cat([diagonal - strongest_image_negative, diagonal - strongest_text_negative]).mean()
    )
    return ContrastiveAlignmentReport(
        image_to_text_accuracy=image_accuracy,
        text_to_image_accuracy=text_accuracy,
        mean_positive_margin=margin,
        aligned=image_accuracy >= min_accuracy
        and text_accuracy >= min_accuracy
        and margin >= min_positive_margin,
    )
```

```python
def siglip_pairwise_loss(logits: t.Tensor, labels: t.Tensor) -> t.Tensor:
    if logits.shape != labels.shape:
        raise ValueError("logits and labels must have the same shape.")
    signed_labels = t.where(labels > 0, 1.0, -1.0).to(logits)
    return F.softplus(-signed_labels * logits).mean()
```

```python
def train_toy_clip_projectors(
    image_features: t.Tensor,
    text_features: t.Tensor,
    *,
    embedding_dim: int = 8,
    steps: int = 250,
    lr: float = 0.05,
    seed: int = 0,
) -> ToyCLIPTrainingResult:
    generator = t.Generator(device="cpu").manual_seed(seed)
    image_projection = t.nn.Parameter(
        t.randn(image_features.shape[1], embedding_dim, generator=generator)
        / image_features.shape[1] ** 0.5
    )
    text_projection = t.nn.Parameter(
        t.randn(text_features.shape[1], embedding_dim, generator=generator)
        / text_features.shape[1] ** 0.5
    )
    optimizer = t.optim.Adam([image_projection, text_projection], lr=lr)
    targets = t.arange(image_features.shape[0])
    losses = []
    for _ in range(steps):
        logits = clip_contrastive_logits(
            image_features @ image_projection, text_features @ text_projection
        )
        loss = (F.cross_entropy(logits, targets) + F.cross_entropy(logits.T, targets)) / 2
        optimizer.zero_grad(set_to_none=True)
        loss.backward()
        optimizer.step()
        losses.append(float(loss.detach()))
    with t.no_grad():
        image_embeddings = image_features @ image_projection
        text_embeddings = text_features @ text_projection
        logits = clip_contrastive_logits(image_embeddings, text_embeddings)
        report = contrastive_alignment_report(logits)
    return ToyCLIPTrainingResult(
        image_projection=image_projection.detach(),
        text_projection=text_projection.detach(),
        image_embeddings=image_embeddings.detach(),
        text_embeddings=text_embeddings.detach(),
        retrieval_logits=logits.detach(),
        train_losses=tuple(losses),
        report=report,
    )
```

## From Projectors to a Complete Pixel-and-Token Model

The warm-up above learned two linear maps from supplied color/shape features. It did **not** learn
to read an image. Now remove those features: our image tower receives only a `(batch, 3, 32, 32)`
RGB tensor, and our text tower receives only token IDs and a padding mask. Labels may construct a
batch and score an answer; they never enter either tower.

**Question:** can both encoders learn a shared space in which a new picture retrieves the right
caption, and a caption retrieves any correct picture?

Follow the data: RGB → three convolution/GELU stages → a learned readout → projection → unit vector.
Caption → token and position embeddings → one causal attention/MLP block → EOS pooling → projection
→ unit vector. Their dot product is a cosine similarity. A learned positive scale controls its
sharpness. The module constructors are supplied; you implement their computations.

This reuses the CNN progression from original ARENA 0.2 and the attention implementation from
original ARENA 1.1. Complete those prerequisites if convolution shapes, residual connections, or
attention heads are unfamiliar. The tiny CNN and single text block are a teaching model, not CLIP's
full architecture. The official checkpoint comparison follows this experiment.

We use 576 training images (48 per class, renderer seed 100), development images from seed 200, and
288 evaluation images (24 per class, seed 300). The 1,200-step schedule was chosen on development
images and then fixed. Final evaluation is never passed to the optimizer. Position, size, color
shade, background and sensor noise vary independently between instances. All twelve color–shape
classes and the caption template are shared across splits. This measures fresh instances, not unseen
concepts or natural images. Zero exact pixel overlap is a useful leak check; sensor noise alone can
make bytes differ, so it does not prove novel geometry.

```python
def tokenize_pixel_captions(
    captions: Sequence[str], vocab: dict[str, int], *, context_length: int = 12
):
    """Right-pad BOS/word/EOS sequences and return an explicit boolean validity mask."""
    ids = t.full((len(captions), context_length), vocab["<pad>"], dtype=t.long)
    mask = t.zeros_like(ids, dtype=t.bool)
    for row, caption in enumerate(captions):
        tokens = [
            vocab["<bos>"],
            *(vocab.get(word, vocab["<unk>"]) for word in caption.lower().split()),
            vocab["<eos>"],
        ]
        if len(tokens) > context_length:
            raise ValueError("caption exceeds context_length; do not silently discard EOS")
        ids[row, : len(tokens)] = t.tensor(tokens)
        mask[row, : len(tokens)] = True
    return ids, mask
```

```python
class PixelImageEncoder(nn.Module):
    """A complete small CNN: RGB pixels -> spatial features -> global representation."""

    def __init__(self, width: int = 32):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 16, kernel_size=5, stride=2, padding=2)
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, stride=2, padding=1)
        self.conv3 = nn.Conv2d(32, 32, kernel_size=3, stride=2, padding=1)
        self.readout = nn.Linear(32 * 4 * 4, width)

    def forward(self, pixels: t.Tensor) -> t.Tensor:
        if pixels.ndim != 4 or tuple(pixels.shape[1:]) != (3, 32, 32):
            raise ValueError("image encoder expects RGB tensors of shape (batch, 3, 32, 32)")
        hidden = F.gelu(self.conv1(2 * pixels - 1))
        hidden = F.gelu(self.conv2(hidden))
        hidden = F.gelu(self.conv3(hidden))
        return self.readout(hidden.flatten(1))
```

### Exercise 7 — Implement causal attention with padding

```python
class PixelTextBlock(nn.Module):
    """One visible pre-norm causal attention/MLP block, including padding exclusion."""

    def __init__(self, width: int = 32, heads: int = 4):
        super().__init__()
        if width % heads:
            raise ValueError("width must divide into complete attention heads")
        self.heads = heads
        self.norm1 = nn.LayerNorm(width)
        self.qkv = nn.Linear(width, 3 * width, bias=False)
        self.attention_out = nn.Linear(width, width, bias=False)
        self.norm2 = nn.LayerNorm(width)
        self.fc1 = nn.Linear(width, 2 * width)
        self.fc2 = nn.Linear(2 * width, width)

    def forward(self, hidden: t.Tensor, valid_mask: t.Tensor) -> t.Tensor:
        batch, length, width = hidden.shape
        if valid_mask.shape != (batch, length) or valid_mask.dtype != t.bool:
            raise ValueError("valid_mask must be a boolean batch-by-length matrix")
        if length == 0 or not bool(valid_mask[:, 0].all()):
            raise ValueError("every sequence needs a valid first token for causal attention")
        q, k, v = (
            self.qkv(self.norm1(hidden))
            .reshape(batch, length, 3, self.heads, width // self.heads)
            .unbind(2)
        )
        q, k, v = (item.transpose(1, 2) for item in (q, k, v))
        allowed = t.ones(length, length, dtype=t.bool, device=hidden.device).tril()
        allowed = allowed[None, None] & valid_mask[:, None, None, :]
        scores = (q @ k.transpose(-2, -1)) / math.sqrt(width // self.heads)
        attention = scores.masked_fill(~allowed, -t.inf).softmax(-1)
        mixed = (attention @ v).transpose(1, 2).reshape(batch, length, width)
        hidden = hidden + self.attention_out(mixed)
        return hidden + self.fc2(F.gelu(self.fc1(self.norm2(hidden))))
```

<summary>Interpretation</summary>

Causality and padding are separate constraints. The EOS query can collect every caption word, while
the word queries cannot read a later EOS or pad token.

```python
    def __init__(self, vocab_size: int, width: int = 32, context_length: int = 12, eos_id: int = 2):
        super().__init__()
        self.eos_id = eos_id
        self.embedding = nn.Embedding(vocab_size, width)
        self.position = nn.Parameter(0.01 * t.randn(context_length, width))
        self.block = PixelTextBlock(width)
        self.final_norm = nn.LayerNorm(width)

    def forward(self, token_ids: t.Tensor, valid_mask: t.Tensor) -> t.Tensor:
        if token_ids.shape != valid_mask.shape or token_ids.ndim != 2:
            raise ValueError("token ids and validity mask must be equal-shaped matrices")
        if token_ids.shape[1] > len(self.position) or valid_mask.dtype != t.bool:
            raise ValueError("use a boolean mask and stay within the position context")
        eos = (token_ids == self.eos_id) & valid_mask
        if not bool((eos.sum(-1) == 1).all()):
            raise ValueError("each caption needs exactly one unmasked EOS")
        hidden = self.embedding(token_ids) + self.position[: token_ids.shape[1]]
        hidden = self.final_norm(self.block(hidden, valid_mask))
        positions = eos.long().argmax(-1)
        return hidden[t.arange(len(hidden), device=hidden.device), positions]
```

```python
        super().__init__()
        self.image_encoder = PixelImageEncoder(width)
        self.text_encoder = PixelTextEncoder(vocab_size, width)
        self.image_projection = nn.Linear(width, embedding_dim, bias=False)
        self.text_projection = nn.Linear(width, embedding_dim, bias=False)
        self.logit_scale = nn.Parameter(t.tensor(math.log(10.0)))
        self.logit_bias = nn.Parameter(t.tensor(-math.log(11.0)))
```

```python
        return F.normalize(self.image_projection(self.image_encoder(pixels)), dim=-1)

    def encode_texts(self, token_ids: t.Tensor, valid_mask: t.Tensor) -> t.Tensor:
        return F.normalize(self.text_projection(self.text_encoder(token_ids, valid_mask)), dim=-1)

        image = self.encode_images(pixels)
        text = self.encode_texts(token_ids, valid_mask)
```

```python
def pixel_alignment_loss(logits: t.Tensor, *, objective: str) -> t.Tensor:
    """CLIP symmetric cross entropy or SigLIP sum-over-pairs divided by batch size."""
    if logits.ndim != 2 or logits.shape[0] != logits.shape[1] or len(logits) == 0:
        raise ValueError("training uses square batches with one example per semantic class")
    count = len(logits)
    labels = t.arange(count, device=logits.device)
    if objective == "clip":
        return (F.cross_entropy(logits, labels) + F.cross_entropy(logits.T, labels)) / 2
    if objective == "siglip":
        signed = 2 * t.eye(count, device=logits.device) - 1
        return F.softplus(-signed * logits).sum() / count
    raise ValueError("objective must be clip or siglip")
```

```python
def semantic_retrieval_metrics(
    logits: t.Tensor, image_labels: t.Tensor, text_labels: t.Tensor
) -> dict[str, float]:
    """Score any semantically correct retrieved instance; split exact top ties fairly."""
    if logits.shape != (len(image_labels), len(text_labels)):
        raise ValueError("labels must describe the rectangular retrieval matrix")
    positive = image_labels[:, None] == text_labels[None, :]
    if not bool(positive.any(0).all() and positive.any(1).all()):
        raise ValueError("every query must have a positive in its gallery")
    top_text = logits == logits.max(1, keepdim=True).values
    top_image = logits == logits.max(0, keepdim=True).values
    i2t = (top_text & positive).sum(1) / top_text.sum(1)
    t2i = (top_image & positive).sum(0) / top_image.sum(0)
    return {"image_to_text": float(i2t.float().mean()), "text_to_image": float(t2i.float().mean())}
```

```python
def train_pixel_dual_encoder(
    model: nn.Module,
    dataset: PixelDataset,
    *,
    objective: str,
    steps: int = 1200,
    seed: int = 0,
    learning_rate: float = 0.002,
    shuffle_pairs: bool = False,
) -> dict:
    """Train directly on RGB and token IDs, sampling one image per class each step."""
    device = next(model.parameters()).device
    generator = t.Generator().manual_seed(seed)
    pair_generator = t.Generator().manual_seed(seed + 10000)
    images = dataset.images.to(device)
    token_ids, valid_mask = tokenize_pixel_captions(dataset.captions, PIXEL_VOCAB)
    token_ids, valid_mask = token_ids.to(device), valid_mask.to(device)
    groups = [
        (dataset.labels == label).nonzero().flatten() for label in range(len(dataset.captions))
    ]
    if steps < 1 or any(len(group) == 0 for group in groups):
        raise ValueError("positive steps and at least one image per caption class are required")
    trainable = [parameter for parameter in model.parameters() if parameter.requires_grad]
    before = {name: parameter.detach().clone() for name, parameter in model.named_parameters()}
    optimizer = t.optim.AdamW(trainable, lr=learning_rate, weight_decay=0.01)
    losses = []
    model.train()
    for _ in range(steps):
        indices = t.stack(
            [group[t.randint(len(group), (), generator=generator)] for group in groups]
        ).to(device)
        order = (
            t.randperm(len(groups), generator=pair_generator).to(device)
            if shuffle_pairs
            else t.arange(len(groups), device=device)
        )
        logits = model(images[indices], token_ids[order], valid_mask[order])
        loss = pixel_alignment_loss(logits, objective=objective)
        optimizer.zero_grad(set_to_none=True)
        loss.backward()
        t.nn.utils.clip_grad_norm_(trainable, 1.0)
        optimizer.step()
        with t.no_grad():
            model.logit_scale.clamp_(0, math.log(100))
        losses.append(float(loss.detach()))
    changes = {}
    for prefix in ("image_encoder", "text_encoder", "image_projection", "text_projection"):
        changes[prefix] = math.sqrt(
            sum(
                float((p.detach() - before[n]).square().sum())
                for n, p in model.named_parameters()
                if n.startswith(prefix)
            )
        )
    return {
        "losses": losses,
        "parameter_change_norms": changes,
        "steps": steps,
        "examples_seen": steps * len(groups),
        "objective": objective,
        "shuffle_pairs": shuffle_pairs,
    }
```

## Signature Result: Learn, Retrieve, and Break the Pairing

The following provided orchestration calls **your** classes, training loop, loss and evaluation
functions from this notebook's namespace. Read the three training conditions before running. They
start from copies of the same initialization and receive the same image batches. Every seed is
retained; the heatmaps and later play cell use the predeclared seed 0, not the best run.

We compare CLIP and SigLIP, each at seeds 0, 1 and 2, with full training, frozen towers and shuffled

changes while its purported target label stays fixed; this is intentionally different from
relabeling a reordered gallery.


```python
def run_pixel_comparison(
    train_data: PixelDataset,
    evaluation_data: PixelDataset,
    *,
    device: str = "cpu",
    seeds: tuple[int, ...] = (0, 1, 2),
    steps: int = 1200,
) -> dict:
    """Visible experiment orchestration; all taught methods resolve in this namespace."""
    rows, histories, matrices, models = [], {}, {}, {}
    overlap = dataset_overlap(train_data, evaluation_data)
    if overlap:
        raise ValueError("evaluation contains training pixels")
    for objective in ("clip", "siglip"):
        for seed in seeds:
            t.manual_seed(seed)
            initial = PixelDualEncoder(len(PIXEL_VOCAB)).to(device)

            def record(condition, result):
                rows.append(
                    {
                        "objective": objective,
                        "seed": seed,
                        "condition": condition,
                        **{key: value for key, value in result.items() if key != "logits"},
                    }
                )
                if seed == seeds[0]:
                    matrices[f"{objective}/{condition}"] = result["logits"]

            record("untrained", evaluate_pixel_model(initial, evaluation_data))
            for condition in ("paired", "shuffled_train", "frozen_towers"):
                model = copy.deepcopy(initial)
                if condition == "frozen_towers":
                    for tower in (model.image_encoder, model.text_encoder):
                        tower.requires_grad_(False)
                history = train_pixel_dual_encoder(
                    model,
                    train_data,
                    objective=objective,
                    steps=steps,
                    seed=seed,
                    shuffle_pairs=condition == "shuffled_train",
                )
                histories[f"{objective}/{seed}/{condition}"] = history
                result = evaluate_pixel_model(model, evaluation_data)
                record(condition, result)
                if condition == "paired":
                    blank = t.ones_like(evaluation_data.images)
                    generator = t.Generator().manual_seed(seed + 700)
                    noise = t.rand(evaluation_data.images.shape, generator=generator)
                    record(
                        "blank_pixels",
                        evaluate_pixel_model(model, evaluation_data, image_override=blank),
                    )
                    record(
                        "noise_pixels",
                        evaluate_pixel_model(model, evaluation_data, image_override=noise),
                    )
                    # Replace every caption's color, retaining its original target label.
                    # This is a semantic mismatch control, not a reordering of the gallery labels.
                    permutation = t.arange(len(PIXEL_CAPTIONS)).roll(3)
                    wrong_logits = result["logits"][:, permutation]
                    record(
                        "wrong_color_words",
                        {
                            **semantic_retrieval_metrics(
                                wrong_logits, evaluation_data.labels, t.arange(len(PIXEL_CAPTIONS))
                            ),
                            "logits": wrong_logits,
                        },
                    )
                    if seed == seeds[0]:
                        models[objective] = model
                print(
                    f"{objective}, seed {seed}, {condition}: "
                    f"image→text {result['image_to_text']:.3f}; "
                    f"text→image {result['text_to_image']:.3f}",
                    flush=True,
                )
    return {
        "rows": rows,
        "histories": histories,
        "matrices": matrices,
        "models": models,
        "train_seed": train_data.seed,
        "evaluation_seed": evaluation_data.seed,
        "train_images": len(train_data.images),
        "evaluation_images": len(evaluation_data.images),
        "exact_pixel_overlap": overlap,
        "seeds": list(seeds),
        "steps": steps,
    }
```

```python
def extract_contrastive_embeddings(
    model,
    batch: Mapping[str, t.Tensor],
) -> tuple[t.Tensor, t.Tensor]:
    if "pixel_values" not in batch or "input_ids" not in batch:
        raise KeyError("batch must contain pixel_values and input_ids.")
    image_output = model.get_image_features(pixel_values=batch["pixel_values"])
    text_kwargs = {"input_ids": batch["input_ids"]}
    if "attention_mask" in batch:
        text_kwargs["attention_mask"] = batch["attention_mask"]
    text_output = model.get_text_features(**text_kwargs)
    image = image_output if isinstance(image_output, t.Tensor) else image_output.pooler_output
    text = text_output if isinstance(text_output, t.Tensor) else text_output.pooler_output
    image, text = image.float(), text.float()
    return (
        image / image.norm(dim=-1, keepdim=True).clamp_min(1e-8),
        text / text.norm(dim=-1, keepdim=True).clamp_min(1e-8),
    )


def bidirectional_retrieval_metrics(
    image_embeddings: t.Tensor,
    text_embeddings: t.Tensor,
    *,
    logit_scale: float = 1.0,
    logit_bias: float | t.Tensor = 0.0,
) -> dict[str, object]:
    logits = clip_contrastive_logits(image_embeddings, text_embeddings, logit_scale=logit_scale)
    logits = logits + t.as_tensor(logit_bias, device=logits.device, dtype=logits.dtype)
    report = contrastive_alignment_report(
        logits, min_accuracy=0.0, min_positive_margin=float("-inf")
    )
    return {"logits": logits, **report.__dict__}
```

```python
def patch_image_region(clean_image, corrupt_image, bbox: tuple[int, int, int, int]):
    patched = clean_image.copy()
    patched.paste(corrupt_image.crop(bbox), bbox)
    return patched


def bbox_to_visual_tokens(
    bbox: tuple[int, int, int, int],
    *,
    image_size: int,
    patch_size: int,
    has_cls_token: bool,
) -> tuple[int, ...]:
    x1, y1, x2, y2 = bbox
    if not (0 <= x1 < x2 <= image_size and 0 <= y1 < y2 <= image_size):
        raise ValueError("bbox must have positive area inside the image.")
    grid = image_size // patch_size
    offset = int(has_cls_token)
    indices = []
    for row in range(grid):
        for col in range(grid):
            px1, py1 = col * patch_size, row * patch_size
            px2, py2 = px1 + patch_size, py1 + patch_size
            if max(x1, px1) < min(x2, px2) and max(y1, py1) < min(y2, py2):
                indices.append(offset + row * grid + col)
    return tuple(indices)
```

```python
def capture_module_output(
    module: t.nn.Module,
    forward_fn: Callable[[], object],
) -> tuple[object, t.Tensor]:
    captured = []

    def save_output(_module, _args, output):
        if not isinstance(output, t.Tensor):
            raise TypeError("the hook point must return a tensor.")
        captured.append(output.detach())

    handle = module.register_forward_hook(save_output)
    try:
        result = forward_fn()
    finally:
        handle.remove()
    if len(captured) != 1:
        raise RuntimeError(f"expected one activation, captured {len(captured)}.")
    return result, captured[0]


def patch_hidden_token_rows(
    clean_activations: t.Tensor,
    corrupt_activations: t.Tensor,
    token_indices: tuple[int, ...] | list[int],
) -> t.Tensor:
    if clean_activations.shape != corrupt_activations.shape or clean_activations.ndim != 3:
        raise ValueError(
            "clean and corrupt activations need matching [batch, token, hidden] shape."
        )
    index = t.tensor(tuple(token_indices), device=clean_activations.device)
    if index.numel() == 0 or index.unique().numel() != index.numel():
        raise ValueError("token_indices must be nonempty and unique.")
    if index.min() < 0 or index.max() >= clean_activations.shape[1]:
        raise ValueError("token index out of range.")
    patched = clean_activations.clone()
    patched[:, index] = corrupt_activations[:, index].to(patched)
    return patched
```

```python
    model,
    embedding_module: t.nn.Module,
    clean_inputs: Mapping[str, t.Tensor],
    corrupt_pixel_values: t.Tensor,
    token_indices: tuple[int, ...] | list[int],
```

```python
        handle.remove()
```

```python
def causal_patch_metrics(
    clean_logits: t.Tensor,
    corrupt_logits: t.Tensor,
    patched_logits: Mapping[str, t.Tensor],
    *,
    target_indices: t.Tensor,
    counterfactual_indices: t.Tensor,
) -> dict[str, object]:
    def margins(logits: t.Tensor) -> t.Tensor:
        rows = t.arange(logits.shape[0], device=logits.device)
        return (
            logits[rows, target_indices.to(logits.device)]
            - logits[rows, counterfactual_indices.to(logits.device)]
        )

    clean = margins(clean_logits)
    corrupt = margins(corrupt_logits)
    rows = []
    for condition, logits in patched_logits.items():
        patched = margins(logits)
        rows.append(
            {
                "condition": condition,
                "mean_margin": float(patched.mean()),
                "mean_effect": float((clean - patched).mean()),
                "all_flip": bool((patched < 0).all()),
            }
        )
    return {"clean_margins": clean.tolist(), "corrupt_margins": corrupt.tolist(), "rows": rows}
```

## Zero-Shot Classification and Typographic Conflict in Pretrained CLIP

The tiny encoders above never learned to read words drawn into images. Their response to a word
overlay would not establish the behavior of pretrained CLIP. We now use the pinned
`openai/clip-vit-base-patch32` checkpoint with twelve class descriptions and **no downstream
fitting**. This is zero-shot classification on our rendered dataset. We do not claim the model's
original pretraining excluded these concepts or this rendering style.

The motivation is the published observation that CLIP can respond to a written concept as well as to
its visual appearance. [OpenAI's multimodal-neuron
study](https://openai.com/index/multimodal-neurons/) demonstrates typographic attacks; our
controlled exercise tests a specific checkpoint and renderer rather than reproducing every result in
that study.

There are 48 scenes: four new layouts per color–shape class, renderer seed 400, a fixed font and no
attack optimization. Each image receives the same ten interventions: a blank white card, correct
words, a conflicting shape name, irrelevant words, or scrambled conflict letters, each placed in
either the background or across the object. Color words stay fixed in the attack. Background cards
never overlap the object. Object cards have a matched blank version so that covering the shape is
not mistaken for a semantic text effect.

```python
def typographic_attack_metrics(
    baseline_logits: t.Tensor,
    condition_logits: t.Tensor,
    true_labels: t.Tensor,
    attack_labels: t.Tensor,
) -> dict:
    """Separate ordinary errors from targeted flips among baseline-correct images."""
    if baseline_logits.shape != condition_logits.shape or baseline_logits.ndim != 2:
        raise ValueError("baseline and condition need equal rectangular logit matrices")
    if true_labels.shape != (len(baseline_logits),) or attack_labels.shape != true_labels.shape:
        raise ValueError("provide one true and attack label per image")
    if bool((true_labels == attack_labels).any()):
        raise ValueError("a targeted attack must name a different class")
    index = t.arange(len(baseline_logits), device=baseline_logits.device)
    true_labels, attack_labels = true_labels.to(index.device), attack_labels.to(index.device)
    baseline_correct = baseline_logits.argmax(1) == true_labels
    prediction = condition_logits.argmax(1)
    baseline_margin = baseline_logits[index, true_labels] - baseline_logits[index, attack_labels]
    condition_margin = condition_logits[index, true_labels] - condition_logits[index, attack_labels]
    denominator = int(baseline_correct.sum())
    return {
        "image_count": len(index),
        "baseline_correct_count": denominator,
        "baseline_accuracy": float(baseline_correct.float().mean()),
        "accuracy": float((prediction == true_labels).float().mean()),
        "attack_choice_rate": float((prediction == attack_labels).float().mean()),
        "targeted_flip_rate": (
            float((prediction[baseline_correct] == attack_labels[baseline_correct]).float().mean())
            if denominator
            else None
        ),
        "mean_margin_change": float((condition_margin - baseline_margin).mean()),
    }
```

### Run the Controlled Overlay Experiment

Rendering, font loading and batching are supplied. The batching helper calls your
`extract_contrastive_embeddings` and `typographic_attack_metrics` explicitly. The entire comparison
loop is shown here so you can inspect which baseline accompanies each condition. It does not train
or tune CLIP.


```python
from part1_clip_siglip_vlm_controls.typography import (
    make_typographic_dataset, plot_typographic_study,
)
def run_typographic_study(
    model, processor, dataset: dict, *, extract_fn, metric_fn, batch_size: int = 24
) -> dict:
    """Provided batching; call the supplied learner extractor and metric explicitly."""
    device = next(model.parameters()).device
    captions = [f"a simple {caption[2:]} on a white background" for caption in PIXEL_CAPTIONS]
    matrices = {}
    for condition, images in dataset["images"].items():
        rows = []
        for start in range(0, len(images), batch_size):
            batch = processor(
                images=images[start : start + batch_size],
                text=captions,
                return_tensors="pt",
                padding=True,
            ).to(device)
            with t.inference_mode():
                image_embeddings, text_embeddings = extract_fn(model, batch)
                rows.append((model.logit_scale.exp() * image_embeddings @ text_embeddings.T).cpu())
        matrices[condition] = t.cat(rows)
    metrics = []
    for condition, logits in matrices.items():
        placement = condition.split("/")[0]
        card_key = f"{placement}/blank_card"
        baseline_key = card_key if card_key in matrices else "clean"
        clean = metric_fn(matrices["clean"], logits, dataset["labels"], dataset["attack_labels"])
        matched = metric_fn(
            matrices[baseline_key], logits, dataset["labels"], dataset["attack_labels"]
        )
        metrics.append(
            {
                "condition": condition,
                "matched_baseline": baseline_key,
                **clean,
                "matched_card_targeted_flip_rate": matched["targeted_flip_rate"],
                "matched_card_margin_change": matched["mean_margin_change"],
                "matched_card_correct_count": matched["baseline_correct_count"],
            }
        )
    return {
        "rows": metrics,
        "matrices": matrices,
        "seed": dataset["seed"],
        "font_sha256": dataset["font_sha256"],
        "font_size": dataset["font_size"],
        "image_count": len(dataset["labels"]),
        "captions": captions,
    }
```

## Interpreting the Result

- **Retrieval success** says paired representations align on this controlled set.
- **Object patch flips** say counterfactual evidence in object-token rows is causally sufficient to reverse the pairwise choice.
- **Background and same-size random preservation** reject patch-size and generic-perturbation explanations.
- **Full-sequence parity** validates the hook and replacement mechanism.
- **Qwen generation** is behavioral grounding only; it does not localize a mechanism.

## Bonus: Hunt an Anomaly

## Limitations

The real-model evidence uses two controlled rendered images, so it is a pinned mechanistic preflight
rather than a broad claim about natural-image retrieval, hallucination, or VLM reasoning. Qwen is
checked behaviorally on two safe prompts. A research-grade extension needs at least twenty held-out
counterfactual scenes, natural-image controls, multiple hook points, and uncertainty across examples
and random control sets.
