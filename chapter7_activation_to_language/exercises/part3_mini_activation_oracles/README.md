# [7.3] Mini Activation Oracles

This section asks one question: can a low-rank oracle answer different questions
about the same activation, or is it only a probe with question-shaped metadata?

The learner first builds an exact three-factor model organism. Its mixed
activations encode color, shape, and their interaction alongside nuisance
channels. Seven exercises then implement activation-question rows, genuine LoRA
layers with frozen base weights, oracle training, independent shortcut and probe
baselines, four OOD splits, off-manifold abstention, and selective factor
patching.

The signature figure is generated by the notebook from these implementations. It
shows:

- exact question routing across all four latent states;
- oracle `1.00` versus text-only `0.50` and activation-only `0.75`;
- parity with a linear probe bank and exact feature classifier at `1.00`;
- `1.00` on held-out-template, new-name, long-context, and adversarial-distractor
  splits;
- `0.988` abstention on seeded random activations;
- a color patch changing answers `[0, 0, 1] -> [1, 0, 0]`, with the untouched
  shape question acting as the negative control.

`solutions.py` retains the pinned TransformerLens `gelu-1l` CUDA experiment as a
separate real-residual mechanics preflight. It is supporting evidence, not the
lesson or signature result, and it does not claim full generative Activation
Oracle or AObench parity.

Key files:

- `7.3_Mini_Activation_Oracles_exercises.ipynb`: learner progression and stubs.
