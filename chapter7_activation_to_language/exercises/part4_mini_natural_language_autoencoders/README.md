# [7.4] Mini Natural Language Autoencoders

This section asks one question: can a short compositional phrase preserve the
behaviorally relevant information in an activation when the visible prompt is
provably uninformative?

The learner first builds an exact courier-state model organism. Every prompt is
paired with all four combinations of route (`north` or `south`) and cargo
(`fragile` or `standard`). Route and cargo occupy known orthogonal activation
directions; prompt identity occupies orthogonal nuisance directions. The eight
exercises then implement the complete activation-to-phrase-to-activation path,
test it after every sub-function, compare it with prompt-only and
opposite-phrase controls, and causally flip the route direction.

The signature figure is generated by the solved notebook and saved as
`arena_ext/assets/mini_nla_signature_result.png`. On the deterministic default
organism, held-out phrase accuracy is `1.0`, NLA reconstruction MSE is about
`0.015`, prompt-only MSE is about `1.281`, opposite-phrase MSE is about `5.140`,
and the reconstructed downstream behavior has near-zero error.

The pinned TransformerLens `gelu-1l` CUDA path in `solutions.py` remains a
supporting GT-3 preflight. It is not loaded by the learner notebook and does not
replace the exact ground-truth lesson. It must be rerun after learner-surface
changes before release.

This section does not claim free-form language generation, discovery of unknown
concepts, arbitrary residual reconstruction, or Anthropic-scale NLA training.
