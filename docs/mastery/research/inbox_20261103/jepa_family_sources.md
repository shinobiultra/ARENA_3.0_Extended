## Scope and corrections to carry into the full Map/Spec

The inventory comes from canonical [syllabus 14.1–14.4/14.6](../../../../infrastructure/extension/syllabus.yaml), [14.4’s family/source notes](../../../../chapter14_jepa_world_models/instructions/pages/04_[14.4]_The_JEPA_Family.md), [14.3’s action/planning notes](../../../../chapter14_jepa_world_models/instructions/pages/03_[14.3]_Action-Conditioned_World_Models_and_Latent_Planning.md), and the [roadmap requirement registry](../../../roadmap_requirement_registry.yml). The older roadmap/registry and current pages differ in section assignments and implementation granularity. Current 14.4’s five CPU fixtures are not native replications of the papers below. Canonical 14.6 is Sudoku/constraint-world work; it supplies a possible controlled transfer organism and does not introduce another named JEPA family.

Four identity corrections matter:

1. **TS-JEPA**, the time-series model in *Joint Embeddings Go Temporal*, **T-JEPA**, the linked remote-sensing temporal model, and **TC-JEPA**, the verified text-conditioned visual model, are distinct. The registry’s “T-JEPA and TC-JEPA time-series” grouping is not an established paper identity. Keep an unresolved slot if another time-series “TC-JEPA” was intended; do not substitute the text-conditioned model silently.
2. **A-JEPA** by Fei/Fan/Huang and **Audio-JEPA** by Tuncay/Labbé/Benetos/Pellegrini are two papers. The second paper also uses the short audio-JEPA/A-JEPA wording internally; the exact author/title/ID combination resolves the alias, not acronym matching.
3. **JEPA-VLA** is the existing cited paper, arXiv:2602.11832. Do not reverse its name into a different “VLA-JEPA” paper. No new robotics family is added here.
4. Public **V-JEPA 2.1 code/checkpoints exist** in the [official V-JEPA 2 repository](https://github.com/facebookresearch/vjepa2), which announces its 2026-03-16 release and lists B/L/g/G models. The older local “wait for stable weights” status must mean local revision/tool/fit qualification remains pending, rather than claiming no public release. The official 2-AC checkpoint is ViT-g; a ViT-L feature-extraction budget does not automatically qualify native 2-AC planning.

## Evidence labels and shared intuition

**M** = current official metadata/abstract inspected. **F** = named full-text method sections inspected, not a complete reproduction/proof audit. **R** = official release/readme inspected. Versions below are the versions displayed by arXiv on the retrieval date; these are paper versions, not pinned code commits. DOI form `10.48550/arXiv.ID` identifies the preprint. No native release has been installed or tested. Where source content does not establish an update rule or anti-collapse guarantee, it is marked unknown rather than filled from a generic JEPA diagram.

A useful family-level question is: **from which context, with which additional information, should which target representation be predictable—and what stops the system from taking a trivial shortcut?** A second question is whether the learned distinctions support a stated readout or intervention. This proposed teaching vocabulary accommodates several designs; it does not make their objectives, teacher updates or mathematical guarantees identical.

For the PRH connection, use [the conditional theorem audit](prh_jepa.md#2-claims-that-should-enter-the-map-and-spec). In the matrix, **P** denotes learned/asymmetric predictor or conditional dynamics, **J** jointly trained/shared cross-modal representations rather than separately trained modalities, **D** a different/fixed/distilled target or non-spectral objective. Every native row also needs its own finite-sample, observation-loss and optimizer audit. None is automatically covered by the identity-predictor population theorem merely because its name contains JEPA.

**U** in every resource cell means CPU/GPU wall time, peak RAM/VRAM, exact native revision and permitted execution allowance are **UNKNOWN and unmeasured**. A tiny CPU analogue is a proposed mechanism tier; a paper-faithful run is a separate future tier. All figures below need visible examples, student-implemented methods, immediate semantic tests, help/solution dropdowns and a Try It Yourself cell. Record predictions before revealing references; exposure to references remains guided practice, not unseen assessment.
