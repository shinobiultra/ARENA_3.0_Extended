## Minimal algorithms

```
propagate: activation[v] = input[v] + sum(activation[u] * weight[u,v] * gate[u,v], u<v)
exact[e] = M(full) - M(full except e)       # signed float32 score storage
IG[e] = mean_k gradient(M(alpha_k * active), gate[e]) * active[e]
select: abs(IG[e]) >= .25; sort; retain sign; round graph score to 6 decimals
path: stable directed search for maximum product(abs(graph score)), depth <=4
intervene: path only; all path edges removed; each path edge removed from full graph
controls: same edge count random nonselected active edges; all selected edges reversed
assemble: one D, three ratios, two margins, inclusive gates, conjunction
```

The student implements these algorithms inline; record helpers do not supply the taught runtime. The helper contains independent stored-value consistency checks and a postcommit path-choice check, not a hidden taught implementation imported by notebook exercises.
