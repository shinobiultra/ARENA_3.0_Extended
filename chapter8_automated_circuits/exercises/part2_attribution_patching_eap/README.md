# [8.2] Attribution Patching and EAP

This section asks one falsifiable question: can a gradient identify the same
causal nodes and edges as exact patching when the mechanism contains a nonlinear
threshold?

The learner first constructs a planted four-sender, four-receiver graph, then
implements exact node patching, corrupt-point attribution, integrated gradients,
exact edge patching, EAP, EAP-IG, and independent agreement diagnostics. The
signature figure is generated by those notebook implementations. It shows the
known `relation gate -> threshold gate` route disappearing under corrupt-point
attribution and reappearing under path integration.

Controls are part of the result:

- a linear positive control has numerical-zero attribution error;
- the decoy sender and unused receiver have exact zero effect;
- a shuffled-delta EAP-IG control has negative correlation and zero top-3 overlap;
- exact patching remains the reference for every approximation.

`verification_report.json` is supporting release evidence only. Its pinned
TransformerLens `gelu-1l` CUDA path checks real hook and logit mechanics, but is
explicitly not the learner-facing signature result or an IOI-scale EAP claim.
