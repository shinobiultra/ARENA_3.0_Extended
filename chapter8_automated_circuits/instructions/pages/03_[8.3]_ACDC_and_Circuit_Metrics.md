## Cold Open - the edge that looks useless

The primary path below contains a product gate. Both of its inputs are required. If you insert only one clean edge into an otherwise corrupt graph, the other input remains zero and the output does not move. Every single-edge insertion therefore scores **zero**, even though six primary edges are individually necessary in the complete graph.

That is the point of this lesson: **ACDC is a sequential intervention algorithm, not `scores > threshold`.**

```python
def run_toy_graph(graph: ToyCircuitGraph, inputs: Mapping[str, float]) -> GraphRun:
    """Run every edge of the toy graph on one set of inputs."""

    _validate_graph(graph)
    _validate_inputs(graph, inputs)
    incoming = {
        node: tuple(edge for edge in graph.edges if edge.receiver == node)
        for node in graph.node_order
    }
    activations: dict[str, float] = {name: float(inputs[name]) for name in graph.input_nodes}
    for node in graph.node_order:
        if node in graph.input_nodes:
            continue
        messages = [activations[edge.sender] * edge.weight for edge in incoming[node]]
        activations[node] = _apply_operation(graph.operations[node], messages)
    return GraphRun(
        activations=activations,
        metric=activations[graph.output_node],
        active_edges=tuple(edge.name for edge in graph.edges),
    )
```

```python
def run_edge_intervention(
    graph: ToyCircuitGraph,
    clean_inputs: Mapping[str, float],
    corrupt_inputs: Mapping[str, float],
    active_edges: Sequence[str] | set[str] | frozenset[str],
) -> GraphRun:
    """Run clean inputs while replacing missing edge messages with corrupt ones."""

    _validate_graph(graph)
    _validate_inputs(graph, clean_inputs)
    _validate_inputs(graph, corrupt_inputs)
    known_edges = {edge.name for edge in graph.edges}
    active = frozenset(active_edges)
    unknown = active - known_edges
    if unknown:
        raise ValueError(f"unknown active edges: {sorted(unknown)}")
    corrupt = run_toy_graph(graph, corrupt_inputs)
    incoming = {
        node: tuple(edge for edge in graph.edges if edge.receiver == node)
        for node in graph.node_order
    }
    activations: dict[str, float] = {
        name: float(clean_inputs[name]) for name in graph.input_nodes
    }
    for node in graph.node_order:
        if node in graph.input_nodes:
            continue
        messages = []
        for edge in incoming[node]:
            sender_value = (
                activations[edge.sender]
                if edge.name in active
                else corrupt.activations[edge.sender]
            )
            messages.append(sender_value * edge.weight)
        activations[node] = _apply_operation(graph.operations[node], messages)
    ordered_active = tuple(edge.name for edge in graph.edges if edge.name in active)
    return GraphRun(activations, activations[graph.output_node], ordered_active)

def normalized_recovery(*, clean_metric: float, corrupt_metric: float, metric: float) -> float:
    """Normalize a circuit metric so corrupt is zero and clean is one."""

    values = t.tensor([clean_metric, corrupt_metric, metric], dtype=t.float64)
    if not t.isfinite(values).all():
        raise ValueError("clean, corrupt, and circuit metrics must be finite.")
    denominator = clean_metric - corrupt_metric
    if abs(denominator) < 1e-12:
        raise ValueError("clean_metric and corrupt_metric must differ.")
    return float((metric - corrupt_metric) / denominator)

def make_toy_evaluator(
    graph: ToyCircuitGraph,
    clean_inputs: Mapping[str, float] = TOY_CLEAN_INPUTS,
    corrupt_inputs: Mapping[str, float] = TOY_CORRUPT_INPUTS,
) -> tuple[MetricEvaluator, float, float]:
    clean_metric = run_toy_graph(graph, clean_inputs).metric
    corrupt_metric = run_toy_graph(graph, corrupt_inputs).metric

    def evaluate(active_edges: frozenset[str]) -> float:
        return run_edge_intervention(
            graph,
            clean_inputs,
            corrupt_inputs,
            active_edges,
        ).metric

    return evaluate, clean_metric, corrupt_metric
```

```python
def initial_deletion_order(
    edge_names: Sequence[str],
    evaluate: MetricEvaluator,
    *,
    clean_metric: float,
    corrupt_metric: float,
) -> tuple[str, ...]:
    """Rank least damaging full-circuit deletions first."""

    names = _validate_edge_names(edge_names)
    full = frozenset(names)
    full_recovery = normalized_recovery(
        clean_metric=clean_metric,
        corrupt_metric=corrupt_metric,
        metric=evaluate(full),
    )
    damages = {}
    for edge in names:
        trial_recovery = normalized_recovery(
            clean_metric=clean_metric,
            corrupt_metric=corrupt_metric,
            metric=evaluate(full - {edge}),
        )
        damages[edge] = full_recovery - trial_recovery
    return tuple(sorted(names, key=lambda edge: (damages[edge], names.index(edge))))

def greedy_acdc(
    edge_names: Sequence[str],
    evaluate: MetricEvaluator,
    *,
    clean_metric: float,
    corrupt_metric: float,
    threshold: float,
    order: Sequence[str] | None = None,
) -> ACDCResult:
    """Delete edges greedily, recomputing the metric after every decision."""

    names = _validate_edge_names(edge_names)
    if not t.isfinite(t.tensor(threshold)).item() or threshold < 0:
        raise ValueError("threshold must be finite and nonnegative.")
    deletion_order = tuple(order) if order is not None else names
    if len(deletion_order) != len(names) or set(deletion_order) != set(names):
        raise ValueError("order must be a permutation of edge_names.")
    active = frozenset(names)
    current_metric = evaluate(active)
    current_recovery = normalized_recovery(
        clean_metric=clean_metric,
        corrupt_metric=corrupt_metric,
        metric=current_metric,
    )
    steps: list[ACDCStep] = []
    removed: list[str] = []
    for edge in deletion_order:
        before_recovery = current_recovery
        trial_active = active - {edge}
        trial_metric = evaluate(trial_active)
        trial_recovery = normalized_recovery(
            clean_metric=clean_metric,
            corrupt_metric=corrupt_metric,
            metric=trial_metric,
        )
        damage = before_recovery - trial_recovery
        if damage <= threshold:
            decision = "remove"
            active = trial_active
            current_metric = trial_metric
            current_recovery = trial_recovery
            removed.append(edge)
        else:
            decision = "keep"
        steps.append(ACDCStep(edge, before_recovery, trial_recovery, damage, decision))
    kept = tuple(edge for edge in names if edge in active)
    return ACDCResult(kept, tuple(removed), threshold, current_recovery, tuple(steps))
```

Implement a full threshold sweep, rerunning the search at every threshold. Then implement:

- **faithfulness:** circuit recovery relative to clean and corrupt;
- **minimality:** damage from deleting each retained edge;

Why pairs? A missing two-edge path is invisible if completeness adds only one omitted edge at a time. The toy backup path makes this failure exact.

```python
def threshold_sweep(
    edge_names: Sequence[str],
    evaluate: MetricEvaluator,
    *,
    clean_metric: float,
    corrupt_metric: float,
    thresholds: Sequence[float],
    ground_truth_edges: Sequence[str],
    order: Sequence[str] | None = None,
) -> tuple[ThresholdSweepPoint, ...]:
    """Run the full deletion search independently at every threshold."""

    if not thresholds:
        raise ValueError("thresholds must be nonempty.")
    truth = set(ground_truth_edges)
    points = []
    for threshold in thresholds:
        result = greedy_acdc(
            edge_names,
            evaluate,
            clean_metric=clean_metric,
            corrupt_metric=corrupt_metric,
            threshold=float(threshold),
            order=order,
        )
        points.append(
            ThresholdSweepPoint(
                float(threshold),
                len(result.kept_edges),
                result.recovery,
                set(result.kept_edges) == truth,
            )
        )
    return tuple(points)

def evaluate_circuit_metrics(
    edge_names: Sequence[str],
    circuit_edges: Sequence[str],
    evaluate: MetricEvaluator,
    *,
    clean_metric: float,
    corrupt_metric: float,
    min_faithfulness: float = 0.95,
    min_edge_damage: float = 0.05,
    max_omitted_gain: float = 0.05,
    max_completeness_subset_size: int = 2,
) -> CircuitMetricsReport:
    """Measure faithfulness, edgewise minimality, and subset completeness."""

    names = _validate_edge_names(edge_names)
    circuit = frozenset(circuit_edges)
    if not circuit or not circuit.issubset(names):
        raise ValueError("circuit_edges must be a nonempty subset of edge_names.")
    for label, value in {
        "min_faithfulness": min_faithfulness,
        "min_edge_damage": min_edge_damage,
        "max_omitted_gain": max_omitted_gain,
    }.items():
        if not t.isfinite(t.tensor(value)).item() or value < 0:
            raise ValueError(f"{label} must be finite and nonnegative.")
    if max_completeness_subset_size <= 0:
        raise ValueError("max_completeness_subset_size must be positive.")

    def recovery(active: frozenset[str]) -> float:
        return normalized_recovery(
            clean_metric=clean_metric,
            corrupt_metric=corrupt_metric,
            metric=evaluate(active),
        )

    circuit_recovery = recovery(circuit)
    minimality = {
        edge: circuit_recovery - recovery(circuit - {edge})
        for edge in names
        if edge in circuit
    }
    omitted = tuple(edge for edge in names if edge not in circuit)
    completeness = {edge: recovery(circuit | {edge}) - circuit_recovery for edge in omitted}
    subset_rows: dict[tuple[str, ...], float] = {}
    for subset_size in range(1, min(max_completeness_subset_size, len(omitted)) + 1):
        for subset in combinations(omitted, subset_size):
            subset_rows[subset] = recovery(circuit | set(subset)) - circuit_recovery
    min_damage = min(minimality.values())
    strongest_subset = max(subset_rows, key=subset_rows.get) if subset_rows else ()
    max_gain = subset_rows.get(strongest_subset, 0.0)
    return CircuitMetricsReport(
        circuit_recovery,
        minimality,
        min_damage,
        completeness,
        {" + ".join(subset): gain for subset, gain in subset_rows.items()},
        strongest_subset,
        max_gain,
        circuit_recovery >= min_faithfulness,
        min_damage >= min_edge_damage,
        max_gain <= max_omitted_gain,
    )
```

```python
def same_size_circuit_report(
    edge_names: Sequence[str],
    circuit_edges: Sequence[str],
    evaluate: MetricEvaluator,
    *,
    clean_metric: float,
    corrupt_metric: float,
) -> SameSizeCircuitReport:
    """Enumerate every same-size circuit, an exact random-circuit null."""

    names = _validate_edge_names(edge_names)
    circuit = frozenset(circuit_edges)
    if not circuit or not circuit.issubset(names):
        raise ValueError("circuit_edges must be a nonempty subset of edge_names.")
    all_rows: list[tuple[frozenset[str], float]] = []
    for candidate in combinations(names, len(circuit)):
        candidate_set = frozenset(candidate)
        recovery = normalized_recovery(
            clean_metric=clean_metric,
            corrupt_metric=corrupt_metric,
            metric=evaluate(candidate_set),
        )
        all_rows.append((candidate_set, recovery))
    discovered = next(value for candidate, value in all_rows if candidate == circuit)
    controls = [value for candidate, value in all_rows if candidate != circuit]
    rank = 1 + sum(value > discovered + 1e-12 for _, value in all_rows)
    pvalue = sum(value >= discovered - 1e-12 for _, value in all_rows) / len(all_rows)
    return SameSizeCircuitReport(
        len(circuit),
        len(all_rows),
        discovered,
        rank,
        pvalue,
        float(sum(controls) / len(controls)) if controls else 0.0,
        float(max(controls)) if controls else discovered,
        tuple(float(value) for value in controls),
    )

def evaluate_toy_ood(
    graph: ToyCircuitGraph,
    circuit_edges: Sequence[str],
    templates: Sequence[tuple[str, Mapping[str, float], Mapping[str, float]]] = TOY_OOD_INPUTS,
    *,
    min_recovery: float = 0.95,
) -> OODCircuitReport:
    """Evaluate the exact circuit on held-out signal scales and nuisance values."""

    if not templates:
        raise ValueError("templates must be nonempty.")
    recoveries = {}
    for name, clean_inputs, corrupt_inputs in templates:
        evaluator, clean_metric, corrupt_metric = make_toy_evaluator(
            graph, clean_inputs, corrupt_inputs
        )
        recoveries[name] = normalized_recovery(
            clean_metric=clean_metric,
            corrupt_metric=corrupt_metric,
            metric=evaluator(frozenset(circuit_edges)),
        )
    worst = min(recoveries.values())
    return OODCircuitReport(recoveries, worst, worst >= min_recovery)
```

```python
def patch_selected_head_results(
    activation: t.Tensor,
    clean_head_results: t.Tensor,
    selected_heads: Sequence[int],
) -> t.Tensor:
    """Patch selected clean head results into a corrupt hook activation."""

    if activation.ndim != 4:
        raise ValueError("head result must have shape [batch, position, head, d_model].")
    if activation.shape != clean_head_results.shape:
        raise ValueError("clean and corrupt head-result tensors must have matching shapes.")
    if not t.isfinite(activation).all() or not t.isfinite(clean_head_results).all():
        raise ValueError("head-result tensors must be finite.")
    heads = tuple(int(head) for head in selected_heads)
    if len(set(heads)) != len(heads):
        raise ValueError("selected_heads must not contain duplicates.")
    if any(head < 0 or head >= activation.shape[2] for head in heads):
        raise ValueError("selected head index is out of range.")
    patched = activation.clone()
    if heads:
        patched[:, :, list(heads), :] = clean_head_results[:, :, list(heads), :]
    return patched
```

## From a head-output patch to a full transformer circuit

The warm-up found useful head outputs. It did not ask which upstream messages
make those heads useful. Now consider the actual IOI prefix:

> Then, Marco and William had a lot of fun at the garden. William gave a computer to

The correct next token is ` Marco`, and the competing subject is ` William`.
These labels come from the sentence, before we inspect model predictions.
We will replace the names with three unrelated names for the corrupt reference,
while continuing to score the original pair of answer labels.

The full candidate graph contains the input residual, every attention-head
result and every MLP output. Each head has three distinct receiver ports:
its Q, K and V residual inputs before layer normalization. MLP inputs and the
final residual before unembedding are receivers too. A sender can connect to
every later eligible receiver; we do not begin with the published IOI heads.

For a receiver with corrupt baseline $r_v'$, the hybrid input is

$$r_v = r_v' + \sum_{u \to v\;\mathrm{retained}} (z_u^{\mathrm{hybrid}}-z_u').$$

The sender on the retained path is recomputed during this forward pass.
Using its frozen clean value would erase all interventions further upstream.
Attention and MLP biases remain inside the corrupt baseline; their constant
contributions cancel when we add component differences.

The next exercises first use a small, genuine transformer with independent
numerical oracles. Only after those tests pass do we load GPT-2. This isolates
hook bugs from failures of circuit discovery.

```python
def build_residual_graph(n_layers: int, n_heads: int) -> ResidualGraph:
    """Construct the complete legal residual graph for sequential attention/MLP blocks."""
    if n_layers < 1 or n_heads < 1:
        raise ValueError("positive layer and head counts are required")
    sources = ["input"]
    receivers = []
    for layer in range(n_layers):
        prefix = len(sources)
        sources.extend(f"L{layer}H{head}" for head in range(n_heads))
        for port in ("q", "k", "v"):
            for head in range(n_heads):
                receivers.append(Receiver(
                    f"L{layer}H{head}.{port}", f"blocks.{layer}.hook_{port}_input",
                    f"blocks.{layer}.hook_resid_pre", head, prefix, prefix + head,
                ))
        receivers.append(Receiver(
            f"L{layer}MLP.in", f"blocks.{layer}.hook_mlp_in",
            f"blocks.{layer}.hook_resid_mid", None, len(sources), len(sources),
        ))
        sources.append(f"L{layer}MLP")
    receivers.append(Receiver(
        "output", f"blocks.{n_layers - 1}.hook_resid_post",
        f"blocks.{n_layers - 1}.hook_resid_post", None, len(sources), None,
    ))
    legal = t.zeros(len(sources), len(receivers), dtype=t.bool)
    for column, receiver in enumerate(receivers):
        legal[:receiver.source_count, column] = True
    return ResidualGraph(tuple(sources), tuple(receivers), legal, n_layers, n_heads)
```

```python
def reconstruct_receiver(corrupt_receiver: t.Tensor, sender_deltas: t.Tensor,
                         active_edges: t.Tensor) -> t.Tensor:

    sender_deltas is [batch, position, sender, d_model]. active_edges is
    [sender] for a scalar receiver or [sender, head] for a grouped Q/K/V hook.
```

```python
def final_position_logits(model, residual: t.Tensor, end_positions: t.Tensor) -> t.Tensor:
    """Unembed only each example's actual end position, preserving right padding."""
    if end_positions.shape != (len(residual),):
        raise ValueError("provide one end position per example")
    end_positions = end_positions.to(residual.device)
    if bool(((end_positions < 0) | (end_positions >= residual.shape[1])).any()):
        raise ValueError("end positions must lie inside the token sequence")
    last = residual[t.arange(len(residual), device=residual.device), end_positions]
    return model.unembed(model.ln_final(last[:, None, :]))[:, 0]


def answer_logit_differences(logits: t.Tensor, answer_ids: t.Tensor) -> t.Tensor:
    if logits.ndim != 2 or answer_ids.shape != (len(logits), 2):
        raise ValueError("use final-position logits and [correct, distractor] token IDs")
    scores = logits.gather(1, answer_ids.to(logits.device))
    return scores[:, 0] - scores[:, 1]


def clean_kl_divergence(logits: t.Tensor, clean_logits: t.Tensor) -> t.Tensor:
    """Mean KL(clean || circuit) over examples and the entire output vocabulary."""
    if logits.shape != clean_logits.shape or logits.ndim != 2:
        raise ValueError("clean and circuit logits need matching final-position matrices")
    clean_logp = clean_logits.log_softmax(-1)
    return (clean_logp.exp() * (clean_logp - logits.log_softmax(-1))).sum(-1).mean()
```

```python
class EdgeIntervention:
    """Execute a real hybrid graph; retained senders are recomputed in this run."""
    def __init__(self, model, clean_tokens: t.Tensor, corrupt_tokens: t.Tensor,
                 end_positions: t.Tensor):
        if model.cfg.attn_only or model.cfg.parallel_attn_mlp:
            raise ValueError("this graph requires sequential attention then MLP blocks")
        if getattr(model.cfg, "n_key_value_heads", None) is not None:
            raise ValueError("this lesson's graph uses equal query/key/value head counts")
        if clean_tokens.shape != corrupt_tokens.shape or clean_tokens.ndim != 2:
            raise ValueError("matched clean/corrupt token matrices must have the same shape")
        model.set_use_attn_result(True)
        model.set_use_split_qkv_input(True)
        model.set_use_hook_mlp_in(True)
        self.model = model.eval()
        self.graph = build_residual_graph(model.cfg.n_layers, model.cfg.n_heads)
        device = next(model.parameters()).device
        self.clean_tokens = clean_tokens.to(device)
        self.corrupt_tokens = corrupt_tokens.to(device)
        self.end_positions = end_positions.to(device)
        self.active_mask = self.graph.legal_mask.to(device=device, dtype=t.float32)
        names = {receiver.baseline_hook for receiver in self.graph.receivers}
        names.add("blocks.0.hook_resid_pre")
        for layer in range(self.graph.n_layers):
            names.update((f"blocks.{layer}.attn.hook_result", f"blocks.{layer}.hook_mlp_out"))
        with t.inference_mode():
            residual, cache = model.run_with_cache(
                self.corrupt_tokens, names_filter=lambda name: name in names,
                stop_at_layer=self.graph.n_layers, return_type=None,
            )
            self.corrupt_logits = final_position_logits(model, residual, self.end_positions)
            self.corrupt_cache = {name: value.detach().clone() for name, value in cache.items()}
            pieces = [self.corrupt_cache["blocks.0.hook_resid_pre"][:, :, None]]
            for layer in range(self.graph.n_layers):
                pieces.extend((self.corrupt_cache[f"blocks.{layer}.attn.hook_result"],
                               self.corrupt_cache[f"blocks.{layer}.hook_mlp_out"][:, :, None]))
            self.corrupt_sources = t.cat(pieces, dim=2)
            self.sender_deltas = t.empty_like(self.corrupt_sources)
            residual = model(self.clean_tokens, stop_at_layer=self.graph.n_layers, return_type=None)
            self.clean_logits = final_position_logits(model, residual, self.end_positions)
        self.hooks = self.make_hooks()

    def make_hooks(self) -> list:
        """Install source caches before receiver reconstruction at each causal stage."""
        hooks = []

        def source_hook(start, count, has_head_axis):
            def save(activation, hook):
                del hook
                values = activation if has_head_axis else activation[:, :, None, :]
                self.sender_deltas[:, :, start:start + count] = (
                    values - self.corrupt_sources[:, :, start:start + count]
                )
                return activation
            return save

        hooks.append(("blocks.0.hook_resid_pre", source_hook(0, 1, False)))
        for layer in range(self.graph.n_layers):
            start = 1 + layer * (self.graph.n_heads + 1)
            hooks.append((f"blocks.{layer}.attn.hook_result", source_hook(start, self.graph.n_heads, True)))
            hooks.append((f"blocks.{layer}.hook_mlp_out", source_hook(start + self.graph.n_heads, 1, False)))

        groups = {}
        for column, receiver in enumerate(self.graph.receivers):
            groups.setdefault(receiver.hook_name, []).append(column)
        for hook_name, columns in groups.items():
            receiver = self.graph.receivers[columns[0]]

            def receive(activation, hook, columns=tuple(columns), receiver=receiver):
                del activation, hook
                mask = self.active_mask[:receiver.source_count, list(columns)]
                if receiver.head is None:
                    mask = mask[:, 0]
                return reconstruct_receiver(
                    self.corrupt_cache[receiver.baseline_hook],
                    self.sender_deltas[:, :, :receiver.source_count], mask,
                )
            hooks.append((hook_name, receive))
        return hooks

    @t.inference_mode()
    def __call__(self, active_mask: t.Tensor) -> t.Tensor:
        if active_mask.shape != self.graph.legal_mask.shape:
            raise ValueError("mask shape must describe the full candidate graph")
        # Validate on CPU before a single device transfer, rather than syncing every hook.
        mask = active_mask.detach().cpu()
        if bool((mask[~self.graph.legal_mask] != 0).any()):
            raise ValueError("mask contains a backward or otherwise illegal edge")
        if not bool(t.isfinite(mask.float()).all()) or bool(((mask < 0) | (mask > 1)).any()):
            raise ValueError("edge weights must lie between zero and one")
        self.active_mask = mask.to(device=self.clean_tokens.device, dtype=self.corrupt_sources.dtype)
        residual = self.model.run_with_hooks(
            self.clean_tokens, fwd_hooks=self.hooks,
            stop_at_layer=self.graph.n_layers, return_type=None,
        )
        return final_position_logits(self.model, residual, self.end_positions)
```

```python
def output_reachable_sources(graph: ResidualGraph, active_mask: t.Tensor) -> set[int]:
    """Backward reachability through additive edges and fixed component computations."""
    active = active_mask.bool().cpu()
    pending = [len(graph.receivers) - 1]
    visited_receivers, sources = set(), set()
    inputs_by_source = {}
    for index, receiver in enumerate(graph.receivers):
        if receiver.output_source is not None:
            inputs_by_source.setdefault(receiver.output_source, []).append(index)
    while pending:
        receiver = pending.pop()
        if receiver in visited_receivers:
            continue
        visited_receivers.add(receiver)
        for source in active[:, receiver].nonzero().flatten().tolist():
            if source not in sources:
                sources.add(source)
                pending.extend(inputs_by_source.get(source, ()))
    return sources
```

### Exercise — run reverse-topological ACDC with a decision trace

> ```yaml
> Difficulty: 🔴🔴🔴🔴⚪
> Importance: 🔵🔵🔵🔵🔵
> Suggested time: 35 minutes
> ```

Implement `greedy_edge_acdc`. Begin with every legal edge. Visit receivers
from output toward input and senders in reverse order. Temporarily delete one
edge, run the current graph again, and accept the deletion if the increase in
loss is strictly below the threshold. Negative damage is allowed.

Keep a trace with the edge, before/trial losses and decision. Skip disconnected
receiver branches only using your reachability function. The checkpoint
arguments are supplied for long GPU runs: save masks and completed decisions
atomically, and resume without repeating those decisions. A fresh threshold
requires a fresh search; filtering a previous score list is not equivalent.

<details><summary>Expected output</summary>

The nonlinear two-path oracle retains four edges with zero final loss. Its recorded decisions can be replayed exactly; nonfinite loss is rejected.

</details>

<details><summary>Help — Work through one receiver first</summary>

After a rejected deletion, restore that edge. After an accepted deletion,
retain the new loss as the baseline for the next trial. Use the original full
legal graph only to define candidates, not to measure all deletion effects.

</details>

<details><summary>Solution</summary>

```python
def greedy_edge_acdc(graph: ResidualGraph, evaluate_loss: Callable[[t.Tensor], float], *,
                     threshold: float, progress_every: int = 100,
                     checkpoint_path: str | Path | None = None,
                     resume: dict | None = None) -> dict:
    """Reverse-topological edge deletion, evaluating every trial in the current graph."""
    if not math.isfinite(threshold) or threshold < 0:
        raise ValueError("threshold must be finite and nonnegative")
    if progress_every < 1:
        raise ValueError("progress_every must be positive")
    if resume is not None and (resume["threshold"] != threshold or resume["initial_edges"] != int(graph.legal_mask.sum())):
        raise ValueError("resume must use the same threshold and candidate graph")
    active = graph.legal_mask.clone() if resume is None else mask_from_result(graph, resume)
    current = float(evaluate_loss(active))
    if not math.isfinite(current):
        raise ValueError("initial graph loss must be finite")
    initial = current if resume is None else resume["initial_loss"]
    trace = [] if resume is None else list(resume["trace"])
    skipped = [] if resume is None else list(resume["skipped"])
    processed = {(row["source"], row["receiver"]) for row in trace}
    skipped_receivers = {row["receiver"] for row in skipped}
    prior_elapsed = 0. if resume is None else resume.get("elapsed_seconds", 0.)
    started = time.monotonic()
    for receiver_index in reversed(range(len(graph.receivers))):
        receiver = graph.receivers[receiver_index]
        if receiver.name in skipped_receivers:
            continue
        if receiver.output_source is not None and receiver.output_source not in output_reachable_sources(graph, active):
            count = int(active[:, receiver_index].sum())
            active[:, receiver_index] = False
            skipped.append({"receiver": receiver.name, "edges_removed": count})
            continue
        for source in reversed(range(receiver.source_count)):
            if not active[source, receiver_index] or (source, receiver_index) in processed:
                continue
            before = current
            active[source, receiver_index] = False
            trial = float(evaluate_loss(active))
            if not math.isfinite(trial):
                raise ValueError(f"nonfinite loss for {graph.edge_name(source, receiver_index)}")
            damage = trial - before
            remove = damage < threshold
            if remove:
                current = trial
            else:
                active[source, receiver_index] = True
            trace.append({"source": source, "receiver": receiver_index,
                          "edge": graph.edge_name(source, receiver_index),
                          "before_loss": before, "trial_loss": trial,
                          "damage": damage, "removed": remove})
            if len(trace) % progress_every == 0:
                print(f"{len(trace)} edge trials; {int(active.sum())} retained; "
                      f"loss {current:.6f}; {time.monotonic() - started:.1f}s", flush=True)
                if checkpoint_path is not None:
                    checkpoint = {
                        "threshold": threshold, "trace": trace, "skipped": skipped,
                        "active_edges": active.nonzero().tolist(), "complete": False,
                        "initial_edges": int(graph.legal_mask.sum()), "initial_loss": initial,
                        "elapsed_seconds": prior_elapsed + time.monotonic() - started,
                    }
                    temporary = Path(str(checkpoint_path) + ".tmp")
                    temporary.write_text(json.dumps(checkpoint))
```

## Faster edge scores: EAP and input-interpolated EAP-IG

An exact ACDC trial reruns the model. EAP estimates the effect of replacing a
clean sender by its corrupt value using the loss gradient at a receiver:

$$s_{u\to v}=(z'_u-z_u)^\top\nabla_{r_v}L.$$

The dot product also sums over positions and examples. We use a loss that
already averages examples, so do not divide by the batch size twice. For IOI,
use negative mean answer logit difference: larger positive scores estimate
harmful corruptions. Rank magnitudes when constructing circuits so inhibitory
edges are eligible too.

Input-interpolated EAP-IG keeps the clean/corrupt **sender differences fixed**,
but averages receiver gradients along interpolated input residuals. All later
activations are recomputed normally. This differs from interpolating every
edge mask or clamping every intermediate activation. We match the authors'
left-endpoint rule, $\alpha=0,1/m,\ldots,(m-1)/m$.

The [authors' implementation](https://github.com/hannamw/EAP-IG/tree/e24bafd3d22af2c59ac5a83e0a6581b89b5c05dd)
and the independent functions below agree on all 32,491 GPT-2 legal scores:
maximum absolute error is 1.28e-6 for EAP and 2.15e-6 for eight-step EAP-IG on
eight discovery prompts. The parity harness adapts tokenization boundaries,
not the published attribution or hook code. You will still evaluate circuits
with exact hybrid interventions; large attribution scores are not a
faithfulness guarantee.

```python
def contract_edge_gradients(corrupt_minus_clean: t.Tensor, receiver_gradient: t.Tensor) -> t.Tensor:
    """Sum over examples, positions and hidden dimensions; retain sender/receiver axes."""

    return t.einsum("bpsd,bphd->sh", corrupt_minus_clean, receiver_gradient)
```

```python
def edge_attribution_scores(model, clean_tokens: t.Tensor, corrupt_tokens: t.Tensor,
                            end_positions: t.Tensor, mean_loss: Callable[[t.Tensor], t.Tensor], *,
                            method: str = "eap-ig-inputs", steps: int = 8) -> t.Tensor:
    """Score all legal edges with fixed endpoint deltas and input-path gradients.

    EAP uses the clean endpoint. EAP-IG uses alpha=0,1/m,...,(m-1)/m,
    matching the authors' left-endpoint quadrature. The loss already averages
    examples, so only average again over integration steps, not batch size.
    This is not integrated gradients over circuit masks or a completeness proof.
    """
    if method not in ("eap", "eap-ig-inputs") or steps < 1:
        raise ValueError("choose eap or eap-ig-inputs and a positive integration count")
    if clean_tokens.shape != corrupt_tokens.shape or clean_tokens.ndim != 2:
        raise ValueError("use aligned clean/corrupt token matrices")
    if model.cfg.attn_only or model.cfg.parallel_attn_mlp or getattr(model.cfg, "n_key_value_heads", None) is not None:
        raise ValueError("use the sequential equal-head attention/MLP graph taught here")
    model.set_use_attn_result(True)
    model.set_use_split_qkv_input(True)
    model.set_use_hook_mlp_in(True)
    graph = build_residual_graph(model.cfg.n_layers, model.cfg.n_heads)
    parameters = list(model.parameters())
    original_requires_grad = [parameter.requires_grad for parameter in parameters]
    was_training = model.training
    device = parameters[0].device
    clean_tokens, corrupt_tokens = clean_tokens.to(device), corrupt_tokens.to(device)
    groups = {}
    for column, receiver in enumerate(graph.receivers):
        groups.setdefault(receiver.hook_name, []).append(column)
    try:
        model.eval()
        for parameter in parameters:
            parameter.requires_grad_(False)
        with t.inference_mode(False), t.enable_grad():
            clean = cache_sender_outputs(model, clean_tokens, graph)
            corrupt = cache_sender_outputs(model, corrupt_tokens, graph)
            differences = corrupt - clean
            scores = t.zeros(graph.legal_mask.shape, device=device, dtype=clean.dtype)
            alphas = [1.] if method == "eap" else [step / steps for step in range(steps)]
            for alpha in alphas:
                interpolated = (corrupt[:, :, 0] + alpha * (clean[:, :, 0] - corrupt[:, :, 0])).detach().requires_grad_(True)
                handles = []

                def replace_input(activation, hook):
                    return interpolated

                hooks = [("blocks.0.hook_resid_pre", replace_input)]
                for hook_name, columns in groups.items():
                    receiver = graph.receivers[columns[0]]

                    def capture(activation, hook, columns=tuple(columns), receiver=receiver):
                        def accumulate(gradient):
                            with t.no_grad():
                                update = contract_edge_gradients(
                                    differences[:, :, :receiver.source_count], gradient,
                                )
                                scores[:receiver.source_count, list(columns)] += update
                        handles.append(activation.register_hook(accumulate))
                        return activation
                    hooks.append((hook_name, capture))
                try:
                    with model.hooks(fwd_hooks=hooks):
                        residual = model(clean_tokens, stop_at_layer=graph.n_layers, return_type=None)
                        loss = mean_loss(final_position_logits(model, residual, end_positions))
                        if loss.ndim != 0 or not bool(t.isfinite(loss)):
                            raise ValueError("the attribution loss must be a finite scalar mean over examples")
                        t.autograd.grad(loss, interpolated)
                finally:
                    for handle in handles:
                        handle.remove()
            scores /= len(alphas)
            if not bool(t.isfinite(scores).all()):
                raise ValueError("attribution scores must be finite")
            return scores.detach().cpu()
    finally:
        for parameter, required in zip(parameters, original_requires_grad, strict=True):
            parameter.requires_grad_(required)
        model.train(was_training)
```

```python
def greedy_score_mask(graph, scores: t.Tensor, edge_count: int) -> t.Tensor:
    """Grow an exact-budget circuit backward from the output using edge-score magnitude.

    A receiver enters the frontier when its component has a selected path to
    the output. This matches the author's greedy selector with prune=False;
    ties use our declared sender/receiver index order. All selected edges can
    reach the output, but some can lack a retained path from the input. Count
    those edges too and determine usefulness with real hybrid evaluation.
    """
    from heapq import heappop, heappush

    if scores.shape != graph.legal_mask.shape or not bool(t.isfinite(scores).all()):
        raise ValueError("scores must be a finite full-graph matrix")
    if edge_count < 0 or edge_count > int(graph.legal_mask.sum()):
        raise ValueError("edge count must be within the full legal candidate graph")
    magnitudes = scores.detach().cpu().abs()
    inputs_by_source = {}
    for column, receiver in enumerate(graph.receivers):
        if receiver.output_source is not None:
            inputs_by_source.setdefault(receiver.output_source, []).append(column)
    mask = t.zeros_like(graph.legal_mask)
    frontier, opened_sources = [], set()

    def add_receiver(column):
        for source in range(graph.receivers[column].source_count):
            heappush(frontier, (-float(magnitudes[source, column]), source, column))

    add_receiver(len(graph.receivers) - 1)
    for _ in range(edge_count):
        _, source, receiver = heappop(frontier)
        mask[source, receiver] = True
        if source not in opened_sources:
            opened_sources.add(source)
            for column in inputs_by_source.get(source, ()):
                add_receiver(column)
    return mask
```

### Exercise — measure greater-than probability mass

> ```yaml

> Importance: 🔵🔵🔵🔵🔵
> Suggested time: 15 minutes
> ```

Implement `greater_than_probability_difference`. Normalize logits over the
whole vocabulary, gather token IDs for `00` through `99`, and assign +1 to
suffixes strictly later than the start year and −1 to earlier/equal suffixes.
Return one value per example so plots can show failures as well as averages.

<details><summary>Expected output</summary>

Forward values and analytic softmax gradients agree with an explicit loop. Giving an unrelated token half the mass changes a perfect score from 1 to **0.5**.

</details>

<details><summary>Help — Work through one receiver first</summary>

The suffix IDs need not be contiguous or numerically ordered in vocabulary
space. Compare the *suffix numbers* 0..99 with the given start suffix, then use
that sign mask with the gathered probabilities.

</details>

<details><summary>Solution</summary>

```python
def greater_than_probability_difference(logits: t.Tensor, suffix_ids: t.Tensor,
                                        start_suffixes: t.Tensor) -> t.Tensor:
    """P(later two-digit suffix) minus P(earlier/equal suffix), per example.

    Probabilities are normalized over the complete vocabulary. Other words
    contribute neither sign, so do not renormalize onto numeric tokens.
    """
    if logits.ndim != 2 or suffix_ids.shape != (100,) or start_suffixes.shape != (len(logits),):
        raise ValueError("provide final logits, 100 ordered suffix IDs and one start suffix per example")
    if bool(((start_suffixes < 0) | (start_suffixes > 99)).any()):
        raise ValueError("start suffixes must be between 00 and 99")
    probabilities = logits.softmax(-1)[:, suffix_ids.to(logits.device)]
    later = t.arange(100, device=logits.device)[None, :] > start_suffixes.to(logits.device)[:, None]
    signs = t.where(later, 1., -1.).to(probabilities)
    return (probabilities * signs).sum(-1)

```

```python
def gt_behavior(logits, clean_logits, corrupt_logits, suffix_ids, start_suffixes):
    current = greater_than_probability_difference(logits, suffix_ids, start_suffixes)
    clean = greater_than_probability_difference(clean_logits, suffix_ids, start_suffixes)
    corrupt = greater_than_probability_difference(corrupt_logits, suffix_ids, start_suffixes)
    gap = float(clean.mean() - corrupt.mean())
    if abs(gap) < 1e-8:
        raise ValueError("Greater-than recovery needs a nonzero clean/corrupt gap.")
    return {
        "mean_probability_difference": float(current.mean()),
        "recovery": float((current.mean() - corrupt.mean()) / gap),
        "fraction_positive_probability_difference": float((current > 0).float().mean()),
        "numeric_probability_mass": float(logits.softmax(-1)[:, suffix_ids.to(logits.device)].sum(-1).mean()),
        "kl_clean_to_circuit": float(clean_kl_divergence(logits, clean_logits)),
        "per_example_probability_difference": current.tolist(),
    }
```

```python
            return -answer_logit_differences(logits, attribution_discovery["answer_ids"]).mean()

        def ioi_attribution_kl_loss(logits):
            return clean_kl_divergence(logits, ioi_engine.clean_logits)

        def ioi_attribution_behavior(logits):
            return circuit_behavior(logits, attribution_engine.clean_logits, attribution_engine.corrupt_logits,
                                    attribution_development["answer_ids"])

        scores_by_method = {}
        for label, method, loss in (
            ("eap", "eap", ioi_attribution_task_loss),
            ("eap-ig-inputs", "eap-ig-inputs", ioi_attribution_task_loss),
            ("eap-ig-kl", "eap-ig-inputs", ioi_attribution_kl_loss),
        ):
            scores_by_method[label] = edge_attribution_scores(
                gpt2, attribution_discovery["clean_tokens"], attribution_discovery["corrupt_tokens"],
                attribution_discovery["end_positions"], loss, method=method, steps=8,
            )
        selectors = (("topk", top_edge_mask), ("greedy", greedy_score_mask)) if corruption == "all-names" else (("greedy", greedy_score_mask),)
        for selection_name, selector in selectors:
            rows = []
            for budget in IOI_EDGE_BUDGETS:
                row = {"edge_count": budget, "methods": {}, "uniform_same_size": []}
                for label, scores in scores_by_method.items():
                    mask = selector(attribution_engine.graph, scores, budget)
                    row["methods"][label] = {**ioi_attribution_behavior(attribution_engine(mask)),
                                              "active_edges": mask.nonzero().tolist()}
                for random_mask in same_size_random_masks(attribution_engine.graph, mask, count=16, seed=701):
                    row["uniform_same_size"].append(ioi_attribution_behavior(attribution_engine(random_mask)))
                rows.append(row)
            comparison = {
                "task": "ioi", "score_selection": selection_name, "corruption": corruption,
                "development": attribution_development, "rows": rows,
                "full": ioi_attribution_behavior(attribution_engine.clean_logits),
                "empty": ioi_attribution_behavior(attribution_engine.corrupt_logits),
            }
            ioi_attribution_comparisons.append(comparison)
            fig = plot_method_curves(comparison)
            plt.show()
            fig.savefig(assets_dir / f"acdc_ioi_{corruption}_{selection_name}_attribution.png", dpi=150)
```

### Limitations and connection to the papers

These are small, controlled GPT-2 studies with 32 discovery examples. The
greater-than holdout changes one wording pattern; it does not test broad
distribution shift. The reference IOI study has no held-out result because
none of its four candidates met the development criteria. Its diagnostic
plots reuse development examples and must not be described as transfer.
The graph contains additive residual connections and fixed component internals;
it does not discover neuron-level structure or attention links between token
positions. Corrupt substitutions can create activations unlike ordinary text,
and results depend on the corruption, metric, greedy order and finite IG grid.

ACDC gives local deletion decisions, not a globally minimal graph. EAP and
EAP-IG rank local or path-averaged first-order effects; nonlinear interactions
can make those rankings poor circuit selectors. Exact edge counts here include
all selected legal edges. The output-frontier selector does not subsequently
prune nodes without an input path, so its budgets must not be equated with a
paper's post-pruning budgets. The sampled completeness probes are bounded
counterfactual tests, not proof over every possible circuit subset.

The full graph uses 32,491 **additive** edges. Fixed connections inside a
component are rerun rather than counted as removable edges. Do not compare this
count directly with a graph convention that also counts fixed direct edges.
The [ACDC paper](https://papers.neurips.cc/paper_files/paper/2023/file/34e1dbe95d34d7ebaf99b9bcaeb5b2be-Paper-Conference.pdf)
and [authors' code](https://github.com/ArthurConmy/Automatic-Circuit-Discovery)
provide the wider experimental context. The numerical parity check uses the
[EAP-IG implementation at a fixed commit](https://github.com/hannamw/EAP-IG/tree/e24bafd3d22af2c59ac5a83e0a6581b89b5c05dd),
including its left-endpoint input-interpolation grid. Matching those scores
validates the implementation under matched inputs; it does not imply that a
small circuit faithfully recovers every task.
