# Introduction


Image-generation interpretability has its own failure modes. A prompt attention
map can look plausible without causing the image region. A latent direction can
change samples only because many directions do. A proposed denoising circuit can
be no more important than a random ablation. A prompt-to-region claim can fail
when the prompt token is removed.

This notebook builds local controls for diffusion attention maps, denoising
circuits, latent directions, and prompt-to-region causal tests. Later notebooks
can use these checks for diffusion LoRAs, AR image-token models, and
model-specific image-generation circuits. The release verification path runs a
pinned Stable Diffusion 1.5 text-to-image preflight on safe shape prompts, scores
the generated images with pinned CLIP, captures DAAM-style cross-attention maps,
and checks that color/shape prompt tokens concentrate more on generated shape
regions than unrelated-token controls. It also ablates target prompt tokens,
compares against random/control-token ablations, preserves simple image-quality
metrics, and rejects white-noise image controls. A pinned SD-Turbo path remains
as a supplemental fast preflight, not the acceptance fallback.


## Content & Learning Objectives

### 1. Diffusion attention region maps

You will test whether prompt attention mass concentrates in a target image
region.

> ##### Learning Objectives
>
> * Treat attention maps as quantitative objects, not screenshots.
> * Measure mass inside and outside a target region.
> * Reject region claims without region-selective attention.

### 2. Denoising circuit ablations

You will compare a proposed denoising circuit ablation against a random-control
ablation.

> ##### Learning Objectives
>
> * Measure whether ablation increases denoising loss.
> * Require specificity over a random component control.
> * Separate denoising relevance from generic model damage.

### 3. Latent directions

You will test whether a latent direction changes an image score over a random
direction control.

> ##### Learning Objectives
>
> * Evaluate latent directions with paired before/after scores.
> * Require effect size and random-direction margin.
> * Avoid accepting visually pleasing but non-specific steering.

### 4. Prompt-to-region causal tests

You will verify that removing a prompt token changes its claimed image region
more than an unrelated-token control.

> ##### Learning Objectives
>
> * Convert prompt-to-region stories into causal tests.
> * Measure target-region score drops.
> * Require the target drop to exceed control drops.

### 5. Real diffusion generation and attention preflight

You will treat image generation itself as a checked artifact: deterministic
safe prompts should produce images whose CLIP scores retrieve the intended text,
and captured cross-attention maps should favor target color/shape tokens over
background-token controls on the generated object region.

> ##### Learning Objectives
>
> * Load a pinned local text-to-image checkpoint on CUDA.
> * Score generated images with a separate pinned CLIP model.
> * Capture cross-attention maps from the denoising UNet.
> * Compare target-token region mass against unrelated-token controls.
> * Keep the claim scope narrower than full SD 1.5 DAAM or denoising-circuit replication.

# Full experiment path


The full local experiment uses a real image-generation model:

1. Load a local diffusion model or AR image-token model within your VRAM budget.
2. First verify basic generation on safe deterministic prompts.
3. Score generated images with an independent image-text model such as CLIP.
4. Cache prompt-token attention maps across denoising steps.
5. Define target image regions with masks, boxes, or segmentation labels.
6. Measure attention mass and region score changes.
7. Ablate proposed denoising circuits and same-size random controls.
8. Steer latent directions and compare against random directions.
9. Remove prompt tokens and check target-region drops over unrelated controls.
10. Document what would make the image-generation interpretation useless.

The checked GPU path for this notebook now uses
`stable-diffusion-v1-5/stable-diffusion-v1-5` revision
`451f4fe16113bff5a5d2269ed5ad43b0592e9a14` with fp16 safetensors, two 512x512
safe shape prompts, fixed seeds, and `openai/clip-vit-base-patch32` revision
`3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268` for alignment scoring. During the
SD1.5 runs, the notebook replaces the UNet attention processors with a capture
processor, aggregates cross-attention maps across spatial resolutions, and
scores color/shape token maps against generated red-square and blue-circle
masks. The acceptance gate requires target tokens to beat unrelated-token
controls, target prompt ablation to reduce the target color region more than a
control-token ablation, generated images to pass simple quality checks, and
white-noise images to fail those checks. A pinned `stabilityai/sd-turbo`
revision `b261bac6fd2cf515557d5d0707481eafa0485ec2` path remains as a faster
supplemental generation/attention preflight.
